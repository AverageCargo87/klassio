# Голосовой ассистент на 11labs — как это сделано в Klassio

> Шпаргалка для коллеги: «говоришь голосом → он отвечает голосом». Коротко, что
> и как, + минимальный код. На примере Klassio (AI-репетитор), но почищено от
> нашей специфики.

---

## Главная идея (1 абзац)

**Ты не собираешь голосовой пайплайн сам.** 11labs **Conversational AI** — это
один облачный сервис, который делает *всё*: распознавание речи (STT) → мозг (LLM)
→ синтез голоса (TTS) → определение, когда человек закончил говорить (turn-taking)
→ перебивание (barge-in). Браузер просто **подключается к нему по WebSocket**, а
их SDK сам берёт микрофон и проигрывает ответ. Тебе остаётся 3 маленькие вещи.

```
Браузер (твой SDK)  ──WebSocket──►  11labs Conversational AI (облако)
  • микрофон                          STT → LLM → TTS → turn-taking
  • воспроизведение ответа            ВСЁ делает он
```

---

## 3 движущиеся части

### 1. Агент в дашборде 11labs (без кода)
Создаёшь «agent» на elevenlabs.io → выбираешь:
- **голос** (любой их голос или свой клон),
- **LLM** (их встроенный gpt-4o-mini и т.п. — или «Custom LLM», чтобы указать
  свой эндпоинт),
- **системный промпт** (кто ассистент, как себя ведёт),
- язык / первая фраза.

Получаешь `agent_id`.

### 2. Бэкенд: выдать короткоживущий signed URL
API-ключ 11labs **никогда не кладём в браузер**. Бэкенд берёт у 11labs временную
подписанную ссылку для подключения:

```ts
// POST /api/voice/signed-url   (Next.js route / любой node-бэкенд)
export async function POST() {
  const r = await fetch(
    `https://api.elevenlabs.io/v1/convai/conversation/get-signed-url?agent_id=${process.env.ELEVENLABS_AGENT_ID}`,
    { headers: { 'xi-api-key': process.env.ELEVENLABS_API_KEY! } }   // ключ только на сервере
  );
  const { signed_url } = await r.json();
  return Response.json({ signedUrl: signed_url });
}
```

### 3. Фронтенд: подключиться их SDK
SDK сам просит микрофон, стримит аудио и проигрывает ответ.

```tsx
import { useConversation } from '@elevenlabs/react';   // npm i @elevenlabs/react

function VoiceButton() {
  const conversation = useConversation();

  async function start() {
    const { signedUrl } = await fetch('/api/voice/signed-url', { method: 'POST' })
      .then(r => r.json());
    await conversation.startSession({ signedUrl, connectionType: 'websocket' });
  }

  return <button onClick={start}>🎙 Поговорить</button>;
}
```

**Всё.** Жмёшь кнопку, говоришь — он отвечает голосом. Перебивание, паузы, очередь
аудио — внутри SDK.

## Опционально: «голос управляет приложением» (client tools / function calling)
Если хочешь, чтобы ассистент не только болтал, но и **что-то делал в UI** (открыл
корзину, показал слайд, поставил фильтр) — описываешь «tool» в дашборде агента, а в
браузере вешаешь обработчик:

```tsx
const conversation = useConversation({
  clientTools: {
    open_cart: (args) => { /* твоё приложение реагирует на голос */ return 'ок'; },
  },
});
```
Агент сам решает, когда вызвать инструмент, по ходу разговора. В Klassio так
рисуются доски/задания урока (`show_board`, `show_trainer` и т.д.).

## Что у Klassio «своё» — тебе это, скорее всего, НЕ нужно

- **WS-прокси на зарубежном сервере.** У нас пользователи в РФ, а Cloudflare у
  11labs режет TLS-фингерпринт браузера с российского IP (≈через 1.6с после
  коннекта). Поэтому браузер у нас идёт не напрямую, а через тонкий WebSocket-прокси
  на не-РФ VPS (сервер→сервер коннект с чистого IP проходит). **Вне РФ это не нужно —
  подключаешься напрямую к 11labs.**
- Куча client-tools под наш канвас урока — специфика Klassio.

## Деньги (грубо)
- **Подписка** 11labs (Creator ~$22/мес … Pro ~$99/мес — за минуты/конкурентность/
  фичи вроде Custom LLM).
- **Переменное за использование** — в основном **TTS** (озвучка) по символам; STT
  обычно входит в минуты плана. У нас озвучка — доминирующая статья (~135 ₽/урок при
  ~5к символов). Считай по своему объёму речи.

## Грабли (коротко)
- **API-ключ — только на сервере.** В браузер уходит лишь signed URL.
- **Signed URL короткоживущий** — минти на каждую сессию.
- Микрофон требует **HTTPS** и **жеста пользователя** (клик), иначе браузер не даст.
- LLM выбираешь в агенте: их встроенный (проще) или **Custom LLM** → свой эндпоинт
  (если нужен свой мозг/данные).

---

## Минимальный чек-лист «с нуля»
1. Завести агента в 11labs (голос + промпт + LLM) → `agent_id`.
2. Положить `ELEVENLABS_API_KEY` в env бэкенда.
3. Эндпоинт `/api/voice/signed-url` (код выше).
4. Кнопка на фронте с `useConversation` + `startSession({ signedUrl })`.
5. (опц.) client-tools, если голос должен управлять UI.

> Тех. стек 11labs Conversational AI = единый сервис: ты не пишешь STT/LLM/TTS/
> turn-taking — только подключаешься. Это и есть весь «секрет» быстрого старта.
