## Ключевые гочи (в коде hub.html)
- `loadScattered` пре-обрабатывает геометрию ШАБЛОНА один раз (toNonIndexed+aBary) → клоны ДЕЛЯТ геометрию/текстуры (детальные модели не плодят память). 5-й арг `collect` — сбор в `movable[]` для перетаскивания; ставит `userData.mid=url+'#'+i` + восстанавливает позицию из localStorage.
- **Мягкий стык диска:** материал пола `transparent:true` + uniform `uSoftEdge`; при softEdge край гаснет по АЛЬФЕ (панорама просвечивает), без светлого uVoid/каймы. Храм (softEdge=0) НЕ тронут.
- **Огонь:** флипбук `flameSheet.clone()` на костёр, `map.offset` крутится в tick ~25fps; гейт `fgate=max(0,(prog-.15)/.85)` — горит ТОЛЬКО в собранном мире. Гоча: клон до загрузки png патчится в onLoad-колбэке (`for(f of fires) f.map.image=t.image`).
- Сервер broad-роуты: `/{name}.glb`, `/pano/{slug}.jpg`, `/{name}.png`, `/m/{path}` (папки gltf). Правки серверных роутов требуют РЕСТАРТА (`node --check` → kill PID на 8781 → запуск заново).
- Камера: сад/лагерь кламп yaw ±110 (оглядеться), храм ±42.
