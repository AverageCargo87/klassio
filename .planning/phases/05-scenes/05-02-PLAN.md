**lib/board/scenes/explain-multiplication-grid.ts** — implement:

The visual layout (centered on canvas):
- Top-right area: write `strA` (multiplier) at (400, 100), then `strB` below it (400, 145), `×` sign at (360, 145)
- draw_line horizontal at y=185 spanning the column width
- For each digit of b from right to left:
  - digit_i = parseInt(strB[i])
  - partial = a * digit_i
  - shift = (strB.length - 1 - i) trailing zeros (padding as spaces in display)
  - say "Умножаем {a} на {digit_i}: {partial}. Сдвиг на {shift} разряд(а)."
  - draw_text partialStr + '0'.repeat(shift) at appropriate y offset below line (y_base + i * 50)
  - wait 600
- Draw second horizontal line below last partial product
- say "Складываем частичные произведения."
- Compute final result (a * b), draw it below second line
- highlight_region on result row
- wait 800, say "Получили {result}."

Coordinate planning (for 2-digit × 2-digit: a≤99, b≤99):
- Column right edge: x=450
- Each digit slot: ~30px
- First number at y=100, second at y=145, first line at y=185
- Partial 1 at y=220, Partial 2 at y=270, second line at y=310, result at y=340

For larger numbers (up to 4-digit × 3-digit per D-01 schema), scale digit slot width to 24px and start at x=280.

Keep layout within 800×600. If strSum.length × 30 > 500, reduce digit slot to 20px.

```typescript
import { registerScene } from './index'
import type { PrimitiveCall } from './types'

export function* explainMultiplicationGrid(args: unknown): Generator<PrimitiveCall> {
  const { a, b } = args as { a: number; b: number }
  if (!Number.isInteger(a) || !Number.isInteger(b) || a <= 0 || b <= 0) {
    throw new TypeError('explain_multiplication_grid: a и b должны быть натуральными числами')
  }

  const result = a * b
  const strA = String(a)
  const strB = String(b)
  const strResult = String(result)
  const DIGIT_W = Math.max(20, Math.min(32, Math.floor(400 / (strResult.length + 2))))
  const RIGHT_X = Math.min(500, 150 + strResult.length * DIGIT_W)
  const Y_TOP = 100

  yield { name: 'say', input: { text: `Умножаем ${a} на ${b} в столбик.` } }

  // Write a
  yield { name: 'draw_text', input: { x: RIGHT_X - strA.length * DIGIT_W, y: Y_TOP, text: strA, fontSize: 32 } }
  yield { name: 'wait', input: { ms: 600 } }

  // Write × and b
  yield { name: 'draw_text', input: { x: RIGHT_X - strB.length * DIGIT_W - 36, y: Y_TOP + 45, text: '×', fontSize: 32, color: 'blue' } }
  yield { name: 'draw_text', input: { x: RIGHT_X - strB.length * DIGIT_W, y: Y_TOP + 45, text: strB, fontSize: 32 } }
  yield { name: 'wait', input: { ms: 500 } }

  // First horizontal line
  const lineLeft = RIGHT_X - (Math.max(strA.length, strB.length) + 1) * DIGIT_W
  yield { name: 'draw_line', input: { x1: lineLeft, y1: Y_TOP + 88, x2: RIGHT_X + 10, y2: Y_TOP + 88, stroke: 'black', strokeWidth: 2 } }
  yield { name: 'wait', input: { ms: 400 } }

  // Partial products for each digit of b (right to left)
  const partials: { value: number; shift: number }[] = []
  for (let i = strB.length - 1; i >= 0; i--) {
    const digit = Number(strB[i])
    const shift = strB.length - 1 - i
    partials.push({ value: a * digit, shift })
  }

  let partialY = Y_TOP + 110
  for (let idx = 0; idx < partials.length; idx++) {
    const { value, shift } = partials[idx]
    const digitOfB = Number(strB[strB.length - 1 - idx])
    const partialStr = value === 0 ? '0' : String(value)
    const trailingZeros = '0'.repeat(shift)
    const displayStr = partialStr + trailingZeros

    yield { name: 'say', input: { text: `Умножаем ${a} на ${digitOfB}: ${value}.${shift > 0 ? ` Записываем со сдвигом на ${shift} позицию.` : ''}` } }
    yield { name: 'draw_text', input: { x: RIGHT_X - displayStr.length * DIGIT_W, y: partialY, text: displayStr, fontSize: 28 } }
    yield { name: 'wait', input: { ms: 700 } }
    partialY += 45
  }

  // Second horizontal line
  yield { name: 'draw_line', input: { x1: lineLeft, y1: partialY, x2: RIGHT_X + 10, y2: partialY, stroke: 'black', strokeWidth: 2 } }
  yield { name: 'wait', input: { ms: 400 } }

  // Final result
  yield { name: 'say', input: { text: `Складываем частичные произведения: получаем ${result}.` } }
  yield { name: 'draw_text', input: { x: RIGHT_X - strResult.length * DIGIT_W, y: partialY + 15, text: strResult, fontSize: 32 } }
  yield { name: 'wait', input: { ms: 700 } }
  yield { name: 'highlight_region', input: { x: RIGHT_X - strResult.length * DIGIT_W - 10, y: partialY + 8, w: strResult.length * DIGIT_W + 20, h: 44, color: '#a5f3fc', duration_ms: 3500 } }
}

registerScene('explain_multiplication_grid', explainMultiplicationGrid as (args: unknown) => Generator<PrimitiveCall>)
```

**lib/board/scenes/explain-long-division.ts** — implement:

Long division visual (classic Russian "уголок" style):
- Write dividend at left (x=100, y=150), draw vertical line at x=100+digits*22+10, draw horizontal line above quotient
- For each step:
  - Determine how many digits of dividend to take for this step
  - Show current working number (left-most digits not yet divided)
  - say "Делим {current} на {divisor}: получаем {q}."
  - draw_text quotient digit to the right of the bracket
  - Multiply: q × divisor = product. Show product below working number.
  - Subtract: current - product = remainder. Show remainder.
  - If remainder === 0 and no more digits: done.
  - If more digits: bring down next digit (append to remainder), show new current.
  - wait 700 between steps.
- At end: say "Частное: {quotient}." or "Частное: {quotient}, остаток: {remainder}."
- highlight result.

Coordinate planning:
- Dividend string at x=80, y=160
- Division bracket: vertical line at x = 80 + strDividend.length * 22, from y=130 to y=180; horizontal line above quotient area to the right
- Quotient digits written right of bracket starting at x_bracket + 20, y=130
- Step rows: y=200, 250, 300, 350... (each step 50px down), capped at 550

```typescript
import { registerScene } from './index'
import type { PrimitiveCall } from './types'

export function* explainLongDivision(args: unknown): Generator<PrimitiveCall> {
  const { dividend, divisor } = args as { dividend: number; divisor: number }
  if (!Number.isInteger(dividend) || !Number.isInteger(divisor) || divisor === 0) {
    throw new TypeError('explain_long_division: делитель не может быть 0')
  }
  if (dividend <= 0 || divisor <= 0) {
    throw new TypeError('explain_long_division: dividend и divisor должны быть натуральными числами')
  }

  const strDividend = String(dividend)
  const DIGIT_W = 22
  const X_LEFT = 80
  const Y_NUMBERS = 160
  const BRACKET_X = X_LEFT + strDividend.length * DIGIT_W + 12
  const Y_BRACKET_TOP = 130
  const Y_BRACKET_BOT = 185

  yield { name: 'say', input: { text: `Делим ${dividend} на ${divisor} в столбик.` } }

  // Draw dividend
  yield { name: 'draw_text', input: { x: X_LEFT, y: Y_NUMBERS, text: strDividend, fontSize: 28 } }
  yield { name: 'wait', input: { ms: 500 } }

  // Draw divisor to the right of bracket
  yield { name: 'draw_text', input: { x: BRACKET_X + 6, y: Y_NUMBERS, text: String(divisor), fontSize: 28 } }

  // Draw division bracket: vertical line + horizontal line above quotient
  yield { name: 'draw_line', input: { x1: BRACKET_X, y1: Y_BRACKET_TOP, x2: BRACKET_X, y2: Y_BRACKET_BOT, stroke: 'black', strokeWidth: 2 } }
  yield { name: 'draw_line', input: { x1: BRACKET_X, y1: Y_BRACKET_TOP, x2: Math.min(790, BRACKET_X + 200), y2: Y_BRACKET_TOP, stroke: 'black', strokeWidth: 2 } }
  yield { name: 'wait', input: { ms: 500 } }

  // Long division algorithm
  let current = 0
  let quotientStr = ''
  let quotientX = BRACKET_X + 6  // x position for next quotient digit
  let stepY = 210  // y for first subtraction row

  for (let i = 0; i < strDividend.length; i++) {
    current = current * 10 + Number(strDividend[i])

    if (current < divisor && quotientStr === '') {
      // Can't divide yet — leading zero in quotient (skip for first digit)
      continue
    }

    const q = Math.floor(current / divisor)
    const product = q * divisor
    const remainder = current - product
    quotientStr += String(q)

    yield { name: 'say', input: { text: `Делим ${current} на ${divisor}: получаем ${q}.` } }

    // Write quotient digit above the bracket line
    yield { name: 'draw_text', input: { x: quotientX, y: Y_BRACKET_TOP + 5, text: String(q), fontSize: 26, color: 'blue' } }
    quotientX += DIGIT_W
    yield { name: 'wait', input: { ms: 500 } }

    if (stepY <= 530) {
      // Write product below current working number
      yield { name: 'draw_text', input: { x: X_LEFT, y: stepY, text: `− ${product}`, fontSize: 24, color: 'grey' } }
      yield { name: 'draw_line', input: { x1: X_LEFT, y1: stepY + 32, x2: X_LEFT + (String(current).length + 2) * DIGIT_W, y2: stepY + 32, stroke: 'black', strokeWidth: 1 } }
      yield { name: 'wait', input: { ms: 500 } }

      // Write remainder
      yield { name: 'draw_text', input: { x: X_LEFT, y: stepY + 40, text: String(remainder), fontSize: 24 } }
      yield { name: 'wait', input: { ms: 600 } }
      stepY += 80
    }

    current = remainder
  }

  // Final quotient and remainder
  const finalQuotient = Math.floor(dividend / divisor)
  const finalRemainder = dividend % divisor
  const conclusionText = finalRemainder === 0
    ? `${dividend} ÷ ${divisor} = ${finalQuotient}.`
    : `${dividend} ÷ ${divisor} = ${finalQuotient}, остаток ${finalRemainder}.`

  yield { name: 'say', input: { text: conclusionText } }
  yield { name: 'highlight_region', input: { x: BRACKET_X, y: Y_BRACKET_TOP - 5, w: Math.min(200, quotientStr.length * DIGIT_W + 20), h: 38, color: '#a5f3fc', duration_ms: 3500 } }
}
```

    - Validate a and b are finite numbers

```typescript
export function* explainDecimalMultiplication(args: unknown): Generator<PrimitiveCall> {
  const { a, b } = args as { a: number; b: number }
  if (!isFinite(a) || !isFinite(b)) throw new TypeError('explain_decimal_multiplication: нужны конечные числа')

  const strA = String(a), strB = String(b)
  const decA = (strA.split('.')[1] ?? '').length
  const decB = (strB.split('.')[1] ?? '').length
  const totalDec = decA + decB
  const intA = Math.round(a * Math.pow(10, decA))
  const intB = Math.round(b * Math.pow(10, decB))
  const intProduct = intA * intB
  const result = intProduct / Math.pow(10, totalDec)

  // Layout: centered around x=400
  const X = 200, Y = 120
  yield { name: 'say', input: { text: `Умножаем десятичные дроби ${a} и ${b}.` } }
  yield { name: 'draw_text', input: { x: X, y: Y, text: `${a} × ${b}`, fontSize: 32 } }
  yield { name: 'wait', input: { ms: 700 } }
  yield { name: 'say', input: { text: `Сначала умножаем как целые числа: ${intA} × ${intB} = ${intProduct}.` } }
  yield { name: 'draw_text', input: { x: X, y: Y + 70, text: `${intA} × ${intB} = ${intProduct}`, fontSize: 28, color: 'grey' } }
  yield { name: 'wait', input: { ms: 700 } }
  yield { name: 'say', input: { text: `Теперь отсчитываем ${totalDec} знак${totalDec === 1 ? '' : 'а'} после запятой в результате.` } }
```

```typescript
export function* explainArithmeticMean(args: unknown): Generator<PrimitiveCall> {
  const { numbers } = args as { numbers: number[] }
  if (!Array.isArray(numbers) || numbers.length < 2 || numbers.length > 8)
    throw new TypeError('explain_arithmetic_mean: нужно от 2 до 8 чисел')
  if (numbers.some(n => !isFinite(n)))
    throw new TypeError('explain_arithmetic_mean: все числа должны быть конечными')

  const count = numbers.length
  const sum = numbers.reduce((acc, n) => acc + n, 0)
  const mean = sum / count

  const X = 150, Y = 120
  yield { name: 'say', input: { text: `Найдём среднее арифметическое ${count} чисел.` } }
  yield { name: 'draw_text', input: { x: X, y: Y, text: 'Среднее арифметическое', fontSize: 28, bold: true } }
  yield { name: 'wait', input: { ms: 600 } }

  // Write all numbers in a row
  const numbersStr = numbers.join(', ')
  yield { name: 'draw_text', input: { x: X, y: Y + 55, text: `Числа: ${numbersStr}`, fontSize: 24 } }
  yield { name: 'wait', input: { ms: 600 } }

  // Show sum
  yield { name: 'say', input: { text: `Складываем все числа: ${numbers.join(' + ')} = ${sum}.` } }
  yield { name: 'draw_text', input: { x: X, y: Y + 115, text: `${numbers.join(' + ')} = ${sum}`, fontSize: 24, color: 'grey' } }
  yield { name: 'wait', input: { ms: 700 } }
```
