# Phase 6.5 — Summary

> Originally planned as "Hetzner WS-proxy". Hetzner banned the account during
> verification (fake-name on virtual card). DigitalOcean rejected the same
> card. Final landing was **h2.nexus** (Russian-friendly reseller, accepts
> SBP, Frankfurt datacenter). Architecture identical, only the hosting
> provider changed.

## What ships in production

**Browser (RU)** → `wss://87.120.93.35.nip.io/?u=...&t=...&s=<HMAC>` → **nginx (TLS termination)** → **Node WS-proxy on 127.0.0.1:3001** → `wss://api.elevenlabs.io/...` → **ElevenLabs**

| Layer | Where |
|---|---|
| TLS termination + WS-upgrade passthrough | nginx on h2.nexus VPS (Debian 11, 87.120.93.35) |
| TLS cert | Let's Encrypt via nip.io (`87.120.93.35.nip.io`) — auto-renewed by certbot |
| Auth gate | HMAC-SHA256 token minted by Vercel, verified by Node proxy |
| Token TTL | 5 minutes |
| Bridge process | Node 20 + `ws` package, `systemd: klassio-voice-proxy.service`, auto-restart on crash |
| Firewall | ufw + h2.nexus side firewall: only 22 / 80 / 443 inbound |
| SSH access | key-only (`klassio_hetzner.pub` — name kept for continuity), password auth disabled |

## Sequence of confirmed wins

1. **h2.nexus IP NOT in CF denylist** — direct `curl` from VPS to 11labs API: HTTP 200
2. **Direct WS test from VPS** — 11labs WSS handshake holds 20+ sec stable (with audio frames)
3. **E2E test client→proxy→11labs** — 380 KB audio over 20 sec, HMAC validated, clean close
4. **Browser UAT with VPN, first attempt** — 11labs metadata frame received, but voice cuts at +625ms with `reason="User ended conversation"`
5. **Root cause: VoicePanel cleanup bug** — `useEffect` with `[conversation]` deps re-runs on every status update, the prior cleanup sees `status==='connected'` and calls `endSession()`. Existed since Phase 6 implementation but masked by the very Cloudflare cut Phase 6.5 was solving. Fixed in commit `c261fb0` (latched conversation in ref + empty deps).
6. **Browser UAT with VPN, second attempt** — voice connects, 33+ sec stable, but agent speaks English as "Professor Echo" (male voice).
7. **Root cause: agent config drift** — `klassio_agent` (`agent_7701kr9c2v7eev3tabzv4f2b0e8b`) had been reset to ElevenLabs's demo template: voice Eric/EN, language en, model `eleven_flash_v2`, LLM `gemini-2.5-flash`, prompt "You are Professor Echo...". Unclear what reset it. Fixed by running `scripts/restore-agent-config.mjs` against the spec in `PHASE-6-SETUP-2026-05-10.md` (Nataly / ru / `eleven_multilingual_v2` / `gpt-4.1-mini` / Russian system prompt). Reproducible — script is in repo.
8. **Browser UAT with VPN, third attempt** — Nataly speaks Russian, holds 40+ sec ✓
9. **Transcript feature added** — chat-style block between Voice and Trainer panels, populated via `onMessage` → bus → TranscriptPanel.
