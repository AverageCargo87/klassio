```typescript
import { z } from 'zod'

export const trainerTaskSchema = z.object({
  id: z.string().min(1),
  type: z.enum(['numeric-input', 'single-choice', 'matching']),
  prompt: z.string().min(1),
  correct: z.union([z.string(), z.number(), z.array(z.tuple([z.string(), z.string()]))]),
  hints: z.array(z.string()).max(3).optional(),
  options: z.array(z.string()).optional(),
})

export const trainerConfigSchema = z.object({
  title: z.string(),
  tasks: z.array(trainerTaskSchema),
})

export type TrainerTask = z.infer<typeof trainerTaskSchema>
export type TrainerConfig = z.infer<typeof trainerConfigSchema>
```

'use client'
import type { TrainerConfig } from '@/lib/trainer/config-schema'
import { NumericInputTask }  from './numeric-input-task'

  config: TrainerConfig

  )
}

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| trainer config JSON → zod parser | JSON config files from public/ are untrusted (could be malformed) |
| user input → answer comparison | Child's text input compared against data-correct attribute |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-01-01 | Tampering | data-correct attribute (DOM) | accept | data-correct is display-only context for data-attributes; answer validation is in-component state comparison against the `task.correct` prop value from parsed config — NOT from reading the DOM attribute at answer time. Child cannot forge correct-answer by mutating data-correct in DevTools because the comparison uses the React prop, not a re-read of the attribute. |
| T-07-01-02 | Information Disclosure | task.correct in DOM | accept | Correct answers are visible in DOM data-correct. Acceptable for a learning tool aimed at 9-11 year olds — the answer is a teaching tool. No sensitive PII involved. |
| T-07-01-03 | Tampering | TrainerConfig JSON | mitigate | zod trainerConfigSchema.parse() at load time — invalid/malformed JSON throws ZodError with clear message before any rendering. File served from Next.js public/ (static, no auth required — acceptable per A6). |
| T-07-01-04 | Denial of Service | useTrainerIdle polling | mitigate | Interval is 5s; cleared on component unmount via useEffect cleanup. Max 1 idle event per 30s (spam guard). No memory leak risk. |
</threat_model>
