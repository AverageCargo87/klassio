# Стенд «Тетрадь»: ребёнок пишет мышкой — ИИ смотрит (2026-07-29)

Запрос Кратова: «помнишь инструмент для записи чего-то мышкой, а ИИ это смотрит? давай такой стенд соберём для теста».
Собрано и проверено вживую. Стенд throwaway (`.tmp/sketches/tutor/`), в прод не идёт.

## Как запустить

```bash
node scripts/yandex-test-server.mjs
```
→ `http://localhost:8781/tetrad` (алиасы `/pero`, `/notebook`). Ссылка есть и на главной стенда.
Ключ Яндекса берётся серверно из `scripts/.yandex-secret.json` — в браузер не уезжает.

## Что внутри

Три независимых способа «посмотреть» на то, что ребёнок сделал мышкой:

| слой | чем | латентность | цена |
|---|---|---|---|
| **1. Глаза** — читает рукопись | Yandex Vision OCR, модель `handwritten` (есть и `page`) | 140–420 мс | ~0,13 ₽/проверка |
| **2. Жест** — разбирает сами штрихи | локально, без сети: обводка · соединение · подчёркивание · зачёркивание · галочка · письмо | 0 мс | 0 ₽ |
| **3. Судья** — выносит вердикт и говорит фразу Ани | DeepSeek V4 Flash (AI Studio) | 0,9–1,8 с | ~0,18–0,23 ₽/ход |

Плюс: голос Ани (Yandex TTS, `alena`), **запись штрихов с таймингами** (реплей «как писал» + метрики: думал до первого штриха, писал, пауз >1 с, стираний, отмен), сохранение образцов в `.tmp/tetrad-samples/*.json + .png`.

7 заданий: счёт · столбик · слово · обведи лишнее · соедини пару · подчеркни · свободный рисунок.

## Проверено (не на словах — прогонами)

- **Кириллица мышкой читается.** «КНОСС» печатными → обе модели OCR прочитали точно, 297/252 мс. Рамки OCR ложатся на буквы ровно (снимок в `.tmp/tetrad-samples/*-knoss.png`).
- **Жесты ловятся все три**, включая отрицательный случай: подчеркнул «Минотавр» вместо «Крит» → «неверно» + подсказка куда смотреть.
- **Судья держит вердикты:** реальная ошибка (21 вместо 19) → «неверно»; сбой распознавания (прочитано 14) → «не понял, прочитай вслух»; пусто → «не понял».
- **Род побеждён:** 0/8 фраз доезжают до ребёнка с «ты обвёл/справилась».

## Что вылезло (главное для продукта)

1. **Квота Vision OCR — 1 запрос в СЕКУНДУ на каталог.** Авто-проверка по паузе упирается в 429 мгновенно; режим «сравнить обе модели» — гарантированный 429 на второй. Сделан ретрай с бэкоффом (в UI видно «ждал квоту»). **На класс детей одной квоты не хватит — поднимать лимит в консоли до пилота.**
2. **Растянутый мелкий растр ломает распознавание.** Когда картинку для OCR делали увеличением холста, распознаватель дорисовывал несуществующие строки («LD _», «7 об» там, где написано «19»). Чернила при этом чистые — проверено снимком. Починено: картинка для OCR **рисуется заново из векторов штрихов** в большом размере, толщина нормируется к высоте (~3%). Растровый путь остался только когда ребёнок стирал ластиком.
3. **Сырой OCR по цифрам — примерно 2 из 3 при дрожащей мышке** (путает 9↔4, 9↔7). Волосок в 2 px не читается вовсе. Отсюда правила: перо не тоньше ~5 px, просить писать крупно, а расхождение в один символ **не считать ошибкой ребёнка** — это уже зашито в промпт судьи.
4. **DeepSeek сам по себе не держит правило про род** — ~17% фраз были «ты обвёл». Промптом не добивается, поэтому на сервере стоит детектор + один короткий ремонтный ход (срабатывает ~1 раз из 8, +1,2 с, +0,2 ₽). ⚠️ Грабля на будущее: **`\b` в JS не видит кириллицу** — первый детектор молчал всегда, границы слова пришлось задавать через `[^а-яё]`.
5. **OpenAI с этой машины закрыт** (403 `unsupported_country_region_territory`), **мультимодальных моделей в Yandex AI Studio нет** (Qwen3 — текстовая). Значит «посмотреть на картинку глазами LLM» в RU-контуре сейчас нельзя; единственные глаза — Vision OCR. Связка получилась целиком RU-safe.

## Цена одной проверки и когда вообще смотреть (правка по фидбэку Кратова 29.07)

Наивный вариант «смотреть после каждой паузы» дорог не из-за частоты опроса, а потому что **пауза случается
посреди ответа**: написал «1», задумался → проверка, дописал «9» → вторая. Один ответ = 2–3 проверки.
Плюс упор в квоту 1 rps. Поэтому переключено:

- **Триггер по кнопке «✓ Я написал — проверь»** — теперь основной, авто-проверка по паузе выключена по умолчанию
  (осталась галкой с пометкой «дороже»).
- **Судья зовётся только при расхождении.** Если OCR прочитал ровно эталон или жест лёг точно в нужное слово —
  вердикт уже известен без LLM, похвала берётся шаблоном (без рода). Замерено на стенде:

| случай | цена | латентность |
|---|---|---|
| верный письменный ответ | **0,13 ₽** (только глаза) | ~180 мс, ответ мгновенный |
| верный жест | **0,00 ₽** | 0 мс |
| расхождение / не разобрал | **0,36 ₽** (глаза + судья) | ~1,7 с |

Урок из 10 заданий при обычной доле ошибок ≈ **1,5–2 ₽** вместо 3,5 ₽. Дальше режется кэшем промпта DeepSeek
(0,075 ₽/1k вместо 0,3 на повторяющемся системном промпте ~650 токенов).

⚠️ Побочка правила «расхождение в один символ = сбой глаз»: реальная детская ошибка «12» вместо «19» тоже
получает мягкое «не понял, прочитай вслух», а не «неверно». Для цифр это, возможно, слишком мягко —
ручка регулировки в промпте судьи (`/api/judge`), решать на живых детях.
