## 3. АВИТО: РАЗМЕЩЕНИЕ

- **Категория:** Услуги → Обучение, курсы → Репетиторы (предметы: начальная школа / окружающий мир). Формат «онлайн-занятия» в параметрах; гео — город (объявление живёт в выдаче города).
- **Статус:** физлицо может размещать репетиторство; для бесплатной волны налоговый вопрос не встаёт. Для платной второй волны — самозанятость (НПД 4%, «Мой налог», лицензия не нужна).
- **Стоимость:** 1–3 бесплатных объявления в категории; дальше оплата за просмотры (~1–20 ₽/просмотр по городу/категории) или разовое размещение. Для автоответа/API нужен кабинет **Авито Pro** (сам бесплатен) + активный тариф (аванс ~600–1000 ₽).
- **⚠️ Ссылки:** в тексте объявления ЛЮБЫЕ ссылки/телефоны/«точка ру» запрещены — отклонение, при повторах бан. В чате шаблонная рассылка одной ссылки = спам-классификация → бан (реальные кейсы). Правило: ссылку — персонально, после диалога, разными формулировками; лучше увести в TG/телефон (не запрещено, если клиент сам дал контакт) и слать там. **Без RU-домена (P0.1) холодным людям ссылку слать нельзя вообще** — «не открывается» = жалоба = ускоренный бан.
- **Объявление:** заголовок без «AI» в лоб — «Репетитор по окружающему миру, 4 класс — онлайн-занятия»; в первых строках честно: «урок ведёт голосовой AI-учитель Аня, ребёнок говорит с ней голосом и решает задания на доске; первое занятие ознакомительное, с участием родителя». Цена НЕ 0 ₽ (модерация режет фиктивные) — рыночные 500–900 ₽, «первая — ознакомительная» в тексте. 3–5 скриншотов урока + короткое видео с голосом Ани (сильно поднимает конверсию). Один город на старт.

## 4. АВТООТВЕТ НА АВИТО (по нарастающей)

1. **День 1 — встроенный автоответ Авито Pro** (0 ₽ при тарифе): Сообщения → ⋮ → «Настроить автоответы». Один текст на все объявления, срабатывает когда офлайн >5 мин. Текст = скрининг: «Здравствуйте! Отвечу лично в течение часа. Чтобы подобрать занятие, напишите: 1) возраст/класс ребёнка 2) есть ли дома компьютер с микрофоном 3) удобные дни/время». Ссылок в автоответе НЕ давать.
2. **Основной — свой бот на n8n + Avito Messenger API** (у тебя уже есть n8n): получить client_id/secret (ЛК → Для профессионалов → Интеграции → API-ключи; нужен платный тариф) → OAuth2 client_credentials → вебхук POST /messenger/v3/…/webhook на n8n Webhook-ноду → логика скрининга Switch/IF-нодами (состояние чата в Data Table: chat_id → этап → ответы) → ответы через POST /messenger/v1/…/messages. Есть готовый community-node `n8n-nodes-avito-api`. ⚠️ n8n должен быть доступен извне по HTTPS (можно повесить на тот же VPS за nginx). Ссылку бот шлёт только в финале диалога, персонализированную.
3. **Интеграторы (Umnico/Wazzup/AvBot…)** — 500–5000 ₽/мес, для 6–10 семей оверкилл. Единственный резон — переадресация чатов Авито в TG, чтобы не пропускать с телефона (AvBot ~500 ₽). n8n делает то же бесплатно.

## 6. СБОР ФИДБЕКА

- **До сессии:** скрининг (возраст, комп+мик, время) — автоответ/бот; согласие за 24 ч до слота.
- **Во время (модератор):** чеклист наблюдения — где завис, где переспросил, счётчик «не поняла», вмешательства; healthz + остаток лимитов открыты.
- **После:** родителю 8–10 вопросов (понятность, доверие к AI, сравнение с репетитором, **WTP: «сколько бы это стоило?»**, NPS/PMF «расстроитесь, если исчезнет?»); ребёнку 5 вопросов устно («что понравилось/скучно, хочешь ещё?»). Транскрипт → скрипт метрик → 3 инсайта в дебриф-лист в тот же вечер.
- **Свод после волны:** completion, латентность-перцентили, счётчики ошибок, топ-5 проблем, цитаты → решение об итерации 2 (и это отчёт начальству).

## 8. РИСКИ (обновлённый топ)

1. **Ссылка не открывается у родителя** (РКН/Vercel) → жалоба «мошенники» на Авито → бан. Митигация: только RU-домен холодным; смоук с мобильного интернета без VPN каждый день сессий.
2. **Бан Авито за перелив трафика** → ссылки персонально/в TG, объявление без ссылок, автоответ без ссылок.
3. **VPS = тройной SPOF** (фронт после self-host + оба голосовых + nip.io) → uptime-монитор, правило «не взлетело за 10 мин → перенос», fallback-ссылка второго стека у модератора.
4. **Лимиты Сбера посреди сессии** → P0.8 до пилота, не более 2 сессий/день, счётчик в ежедневном чеклисте.
5. **Юр-хвост** → нет согласия за 24 ч — нет сессии; РКН подано до первой холодной сессии.
