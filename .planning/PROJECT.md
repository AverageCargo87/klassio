## Project name

**Klassio** — AI-репетитор математики для российских пятиклассников.

Бренд: имя проекта = имя рабочей папки. Подтверждено отсутствием возражений со стороны юзера и совпадением с `Klassio/` в файловой структуре.

## Core value (один абзац)

Klassio v1 — это **платформа урока**: одно веб-приложение, в котором голосовой AI-учитель ведёт ребёнка через персональный 45–60 минутный урок математики. Урок состоит из трёх синхронных каналов — голос (бот говорит), доска (бот рисует объяснения live, под конкретную ошибку этого ребёнка через tldraw + методические сцены), HTML-тренажёр (ребёнок решает задания, бот видит каждый ввод). Ребёнок попадает в личный кабинет, видит расписание, проводит урок без установки чего-либо (никаких VPN, плагинов, регистраций для ребёнка), а после урока запись и транскрипт доступны в ЛК. Платформа задеплоена так, что российский ребёнок открывает сайт без VPN: фронт на Vercel + Cloudflare, голосовой backend-прокси на Hetzner Frankfurt (для WebSocket к 11labs), Vercel сам ходит к OpenAI с американского IP. **v1 — это сама платформа урока, без воронки клиентов** (Авито, Telegram-бот, диалоговый сбор программы и автоотчёт родителю — следующая итерация).

## v1 scope summary

**v1 = платформа урока.** Никакого маркетинга, никакой воронки.

### Что входит в v1

- **Страница урока** (главное): голос (11labs Conversational AI Path A через Hetzner-прокси) + интерактивная доска (tldraw v3 + OpenAI gpt-4o-mini, текущий прототип превращается в production) + HTML-тренажёр (контракт `data-` атрибутов + event bus). Все три канала работают синхронно — это инвариант продукта.
- **Личный кабинет (ЛК) ребёнка**: список уроков, расписание, доступ к записям прошедших уроков (видео+транскрипт).
- **Авторизация ребёнка** в ЛК через личную ссылку (минимально безопасный способ, без публичных регистраций).
- **2D-аватар** учителя на Lottie с состояниями (нейтрально, говорит, думает, радуется, огорчился).
- **Двухуровневая LLM**: Pedagogical (медленная стратегия) + Realtime (быстрый actor).
- **Структура tools «Сцены»**: переход от 9 примитивов к 12–15 методическим сценам программы 5 класса.
- **Stroke-drawing анимация** + SSML-маркеры для синхронизации речи и рисунка.
- **Запись урока** + транскрипт + контент-модерация + согласие 152-ФЗ.
- **Production deploy**: Vercel (фронт) + Hetzner Frankfurt (voice WS-прокси) + Cloudflare (РФ edge).

### Что НЕ входит в v1 (deferred)

- ❌ Лендинг проекта (нет публичной страницы, ребёнок попадает по личной ссылке).
- ❌ Объявление на Авито и канал привлечения вообще.
- ❌ Telegram-бот для родителя.
- ❌ Диалоговый сбор программы — в v1 уроки и расписание заводятся **вручную** (admin UI или прямо в БД).
- ❌ Автоотчёт родителю в Telegram.
- ❌ Платежи, биллинг.
- ❌ Hand-drawn стиль через rough.js (после MVP).
- ❌ Vision LLM для чтения детских рисунков (V2).
- ❌ Групповые уроки, адаптивная программа, отчёты с динамикой.

Полный список долгосрочного видения — в `VISION.md` § «Долгосрочное видение».

## v1 success metric (developer-facing)

**Один полный 45-минутный урок проходит end-to-end без вмешательства разработчика:**

1. Ребёнок (тестовый юзер) открывает личную ссылку → авторизуется в ЛК.
2. Видит расписание → выбирает запланированный урок.
3. Проводит урок: голос + доска + тренажёр работают синхронно. Бот рисует и объясняет на доске, ребёнок взаимодействует с заданиями в HTML-тренажёре, голос отвечает на ввод.
4. После завершения — запись урока сохранена и доступна в ЛК.

Это и есть «релиз v1 готов».

## Locked decisions

> Эти решения зафиксированы юзером путём явного утверждения v1 scope, который на них опирается. Источник: `.planning/intel/decisions.md` + v1 scope lock 2026-05-09.

| ID | Решение | Scope | Lock rationale |
|---|---|---|---|
| **DEC-board-llm-provider** | OpenAI как primary LLM-провайдер для доски (Anthropic избегаем). | LLM provider for board. | Anthropic режется по TLS-фингерпринту JA3/JA4 за Cloudflare для РФ — не лечится сменой IP. См. `CON-anthropic-rf-block`. |
| **DEC-board-current-model** | Текущая модель доски — `gpt-4o-mini`. | LLM модель для `/api/draw`. | Стабильная экономика ~22 копейки на разбор, function calling работает. См. `CON-board-cost`. |
| **DEC-board-canvas-stack** | tldraw v3.x + Next.js 15 App Router + React 18. | Frontend stack для доски. | tldraw v4 ломает API; React 19 не тестировался под tldraw v3. См. `CON-frontend-libs`, `CON-runtime-versions`. |
| **DEC-board-tool-choice-required** | OpenAI агент-цикл с `tool_choice: 'required'` + служебный `finish` tool. | LLM agent loop. | Без `required` модель отвечает текстом и обрывает цикл. См. `CON-agent-loop`. |
| **DEC-deploy-architecture** | Production deploy = Vercel (фронт) + Hetzner Frankfurt (voice backend-прокси) + Cloudflare (CDN для РФ-юзеров). Юзер открывает сайт без VPN. | Production deployment topology. | Vercel IP не в стоп-листе OpenAI; Hetzner Frankfurt держит WS к 11labs; Cloudflare обслуживает фронт через московские edge. |
| **DEC-voice-provider-mvp** | Голосовой агент = 11labs Conversational AI (Путь A) с Custom LLM endpoint. | Voice agent provider for v1. | Скорость MVP. Свой voice pipeline (Путь B) — следующая итерация для unit-экономики. |
| **DEC-avatar-style** | Аватар учителя — 2D через Lottie, 5–7 состояний. НЕ 3D, НЕ видео-аватар D-ID. | Visual avatar implementation. | 3D и видеогенерация слишком дороги в realtime, плохи для русского, не нужны для 5 класса. |
| **DEC-llm-architecture-tier** | Двухуровневая LLM: Pedagogical (медленный стратег, GPT-4o) + Realtime (быстрый actor, gpt-4o-mini). | LLM architecture pattern. | Стандартный паттерн voice-agents. |

Любое отступление от этих решений требует явного нового decision (через `/gsd-add-decision`) и пересмотра соответствующих фаз.

## Constraints summary

Полный список — `.planning/intel/constraints.md` (18 ограничений, разбито по типам: api-contract, schema, protocol, nfr).

### Критические RU-specific (mandatory awareness)

| ID | Что | Решение в v1 |
|---|---|---|
| **CON-openai-rf-block** | `api.openai.com` режет российские IP с `403 unsupported_country_region_territory`. | Dev: VPN-туннель (TUN-mode, уже работает у юзера). Prod: Vercel ходит к OpenAI с американского IP. |
| **CON-anthropic-rf-block** | `api.anthropic.com` режет по TLS-фингерпринту JA3/JA4 через Cloudflare — не лечится сменой IP. | **Anthropic избегаем по умолчанию.** Если возникнет необходимость (Pedagogical LLM экономика на Claude дешевле) — нужен отдельный decision + CF Worker proxy. По умолчанию ВСЕ LLM в v1 через OpenAI или OpenAI-совместимые провайдеры. |

### Версии runtime (locked)

| Что | Версия | Почему locked |
|---|---|---|
| Node.js | ≥ 20 | `node:` URI imports, нативный fetch (Undici) |
| Next.js | ^15.5.18 (App Router) | НЕ Pages router — нужен streaming response из route handlers |
| React | ^18.3.1 | НЕ 19 — tldraw v3 не тестировался под React 19 |
| tldraw | ^3.15.6 | НЕ 4.x — ломается API |
| TypeScript | ^5 strict | — |
| Tailwind | ^4 | новый CSS-only синтаксис |

### Стоимостный watermark

`gpt-4o-mini` на разборе столбикового сложения = ~$0.0027 ≈ 22 копейки. См. `CON-board-cost`. При переходе на сцены (бóльший контекст) и Pedagogical LLM (повторные round-trips) — следить, чтобы стоимость одного урока оставалась в разумных пределах для unit-экономики.

### Operational gotchas (НЕ удаляй)

- `tool_choice: 'required'` для board LLM — без этого agent-loop обрывается.
- `outputFileTracingRoot` в `next.config.ts` — без этого Next.js находит `~/package-lock.json` юзера.
- TextShape: `richText` (helper `toRichText`); ArrowShape: `text: string` plain — НЕ перепутать.
- `parsed_arguments` от OpenAI SDK обычно `null` — обязательный fallback `JSON.parse(arguments)`.
- `instrumentation.ts` + undici через `createRequire` — webpack не статически анализирует.

## Anti-scope (что НЕ делаем — для отсева идей)

### Не делаем в v1 (deferred to v2+)

- ❌ Лендинг, маркетинговый сайт.
- ❌ Объявление на Авито, канал привлечения.
- ❌ Telegram-бот для родителя.
- ❌ Диалоговый AI-сбор программы (в v1 — вручную).
- ❌ Автоотчёт родителю в Telegram.
- ❌ Платежи, биллинг, подписки.
- ❌ Hand-drawn стиль через rough.js.
- ❌ Vision LLM для рисунков ребёнка.
- ❌ Платформа для учителей (учителя не создают уроки в Klassio).
- ❌ Школьная LMS (журналы, групповые домашки).
- ❌ Групповые уроки, диаризация.
- ❌ Адаптивная программа (бот сам выбирает следующее задание под слабые места).
- ❌ Расширение на 3–4 класс, на другие предметы — после стабильной 5 класс программы.

### Не делаем НИКОГДА (продуктовая идентичность)

- ❌ **НЕ Khanmigo-клон** (бесплатный, англоязычный, без голоса, без своей доски).
- ❌ **НЕ обычный AI-чат** (это уже умеют все).
- ❌ **НЕ предзаписанные видеоуроки** (РЭШ, Учи.ру, Я-класс не могут адаптироваться к ошибке ребёнка).
- ❌ **НЕ платформа для учителей** (уроки генерим мы — LLM + методист в петле).
- ❌ **НЕ школьная LMS** (один-на-один с ребёнком, не журналы и групповые домашки).
- ❌ **НЕ 3D-аватары и НЕ видеогенерация** (D-ID и подобное).

## Product invariants (guardrails при любых архитектурных решениях)

Эти принципы **сильнее любых фич**. Если решение нарушает инвариант — оно отвергается, даже если технически проще.

### 1. Голос + рука + текст — синхронно

В каждый момент урока работают **три канала параллельно**:
- ребёнок слышит голос учителя,
- видит как бот рисует на доске,
- параллельно у него на экране подсвечивается элемент в HTML-тренажёре.

Любое решение, которое разрывает эту триаду («давайте сначала бот говорит, потом рисует») — против духа продукта. Это инвариант, не фича.

### 2. Live-объяснения, не заготовленные

Бот разбирает **именно эту** ошибку именно этого ребёнка. Не «вот видео про сложение в столбик» — а «ты ввёл 11 в 3×4, давай нарисуем». Это и продаёт продукт родителю, это и отличает от Учи.ру/Алгоритмики/любого видео-курса. Никаких предзаписанных решений — каждый разбор генерируется LLM с нуля.

### 3. Проактивный, не реактивный бот

Бот реагирует не только на голос ребёнка, но и на triggers пассивности: молчание > 20 секунд, `visibilitychange`, неправильные ответы подряд, быстрые «потыкивания», нажатие «помощь». Если ребёнок «выпал» — бот замечает и подключается, не ждёт пока тот сам попросит.

### 4. Юзер не должен ставить ничего

Инвариант продукта. Ребёнок открыл сайт → разрешил микрофон → начал урок. Никаких VPN, расширений, плагинов, регистраций со стороны ребёнка (родитель — отдельный сценарий, в v1 родителя в потоке нет вообще).

### 5. Ощущение живого учителя у доски

Это не просто голос с tool calls. Нужны: stroke-drawing анимация (линии «вытягиваются», не появляются), SSML-маркеры для синхронизации речи и рисунка, естественные паузы (`wait` tool), безопасная контент-модерация — всё это вместе создаёт впечатление живого учителя, а не «AI-чата с картинками».

## Контракт работы Claude Code в Klassio

При обсуждении любой новой задачи — **отталкивайся от этого документа и от `VISION.md`**, не от «стандартных» решений из тренинговых данных:

- Это **российский** рынок: учитывай ограничения с API, тестируй промпты на русском, проверяй чтобы LLM не сваливалась в английский в tool calls.
- Это **детская** аудитория: возрастная адаптация, безопасность, проактивность не опциональны.
- Это **продукт на продажу**, не open-source pet-project: смотри на unit-экономику, цену запроса, latency. Каждое архитектурное решение проходит проверку «выдержит ли это 100 одновременных уроков».
- **Голос + рисунок + текст одновременно** — главная фича. Любое решение, которое разрывает эту триаду — против духа продукта.
- При сомнениях — **спрашивай**, не предполагай. Кратов в курсе всех контекстов и решит быстрее.
- Прежде чем вкатывать большую переделку — читай `BOARD-STATUS.md` (история сессий) и `.planning/intel/context.md`, там описаны граблищи прошлых сессий (особенно по сетке и tldraw v3 quirks).
