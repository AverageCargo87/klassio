**Витрина `/lab`** (10.08, перестроена 11.08) — вход для руководителя. Буква = ВЕТКА подачи:
АЛЬФА — учебник-листалка (v2.6, архивы v1.0/v2.3 под её карточкой), БЕТА — повтор параграфа
(`/zakrep`, открывается после урока). Плюс обзор материалов `/kniga/obzor` — всё содержимое
урока одним экраном. У каждой ветки описание, кнопка входа и «что изменилось» с лентой
«что и во сколько выходило» (режется из журнала версий и времён релизов, руками не пишется),
внизу — приём замечаний с фото. Приёмка `scripts/check-lab.mjs`, 53 проверки по боевому адресу. Живёт на российском VPS —
`.planning/LAB-DEPLOY-RUNBOOK.md`.

🔑 **Откат (11.08).** Выкладка `node scripts/lab-deploy.mjs -m "зачем"` кладёт КАЖДУЮ
версию отдельной папкой-релизом и переключает ссылку; не встало — сервер сам возвращает
прежнюю. Сказали «фигня» — `node scripts/lab-rollback.mjs --back`, секунды. Исходники
сборок зеркалятся под git в `lab/` с меткой `lab-000N`, журнал выкладок —
`.planning/LAB-RELEASES.md`.
⚠️ **v2.4 отдельной сборкой не существует** — v2.5 легла поверх неё в тот же круг. Журнал версий с подробностями и граблями —
`.planning/KNIGA-VERSIONS.md`, хендофф — `.planning/SESSION-2026-08-05-KNIGA-V2.md`.

🔑 **Закон формы, на котором всё держится:** 90 % времени звучит текст учебника, учебник —
стопроцентный вариант истины. Отсюда и масштабирование на другие параграфы, и контроль.
Каждый раз, когда просят «добавить своего», это решение принимается отдельно.

**`/zakrep` (06.08) — вторая ветка подачи.** Экран закрепления по референсу Anatomy Atelier:
из него вырос экран топиков в v2.4, а 11.08 он включён в урок как **повтор всего параграфа**
после итогов — «чтобы весь урок заново не слушать». Данные общие с уроком.

## Как читать эту карту

- **Развиваем одно** — `/kniga`. Номер версии виден в заголовке вкладки и плашкой в нижней
  панели урока, прошлые сборки открываются по `/kniga/vN`.
- **Ветки 2 и 3 не «недоделаны»** — по ним есть решения. Возврат к любой = смена формы, а
  не продолжение работы.
- Если добавляется новая ветка — сначала строка в этой таблице, потом код.
