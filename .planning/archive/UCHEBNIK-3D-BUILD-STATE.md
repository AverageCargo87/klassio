# V2 — «урок как 3D-объекты на парте» (`v2.html`)

**Задача Кратова:** учебник/тетрадь/карандаш и т.д. = 3D-объекты на парте (не полноэкранный iframe),
с сохранением функционала: перелистывание страниц, ответы в тетради и т.д.

**Архитектура:** гибрид WebGL (класс из v1) + **CSS3DRenderer** (three/addons/renderers/CSS3DRenderer.js):
страницы учебника, тетрадь, стикер-словарик = интерактивные DOM-плоскости, лежащие на парте в мировых
координатах (rotation.x=-PI/2, scale 0.0005: див 1040×680px → разворот 0.52×0.34 м). Перелистывание =
GSAP rotateY «листа» ВНУТРИ CSS3D-плоскости (preserve-3d) — страница реально поднимается в 3D.
Контент урока НЕ iframe: пересобран мной (разметка как в `.tmp/sketches/tutor/uchebnik-desk.html`,
контент — инвестиции из промпта для Claude Design: 6 разворотов inflation/shares/income/risk/compound/reward,
задачи q1 choice/q3 blank(кусочек)/q7 choice/q10 blank(яйца)/q13 choice(Соня-Тимур), словарик, реплики Ани).

**Ключевые решения:**
- Слои: canvas WebGL → CSS3D-контейнер (z-index 5, pointer-events:none контейнер) → экранный UI (z 30+).
  Интерактив CSS3D-дивов включается только в режиме desk: `body.mode-desk .i3d{pointer-events:auto}`.
- Сидя 3 подрежима: seated-free (виден весь стол) → клик по книге/тетради = «наклониться» (камера
  почти top-down над объектом, читаемо как 2D) → «Откинуться». Плюс v1-режимы «доска»/«встать».
- Известный компромисс: CSS3D рисуется поверх WebGL всегда → спинка стула не заслоняет книгу
  при взгляде сзади-снизу. Для спайка ок.
- Аня = экранная карточка (top), док снизу: ‹ › листать + «Демо-прогон». Демо: сама открывает,
  листает, наклоняется к тетради, решает.
- Отладка: `window.__uch3d` как в v1 + `window.__lesson` (open/flip/focus/task/solve).

## Правка 2026-07-03 №3 (мик-тест №2: «улетело пол-учебника», дубль-UI, доска)
Симптом: Аня говорит «открываю первую страницу», а книга уже на «Риске» (стр. 8-9, q8). Причины:
(а) сигнал о ручном флипе шёл с trigger=true НА КАЖДЫЙ клик стрелкой → каждый клик дёргал её на реплику+флип;
(б) гвард темпа (6с) не держит МЕЖДУ ходами — модель звала next_slide каждый ход. Сделано:
1. **Жёсткий гейт прогресса (как в боевом уроке):** листать дальше НЕЛЬЗЯ, пока не решены задания текущего
   разворота (`maxAllowedIndex` по `solved`-сету из `onSolve`; TASKS_BY_SPREAD: inflation q1-2 / shares q3-4 /
   income q5-7 / risk q8-10 / compound q11-13). `next_slide`/`show_board`/`show_trainer`/`give_reward`
   возвращают «Рано…» с точной причиной. `show_trainer` не даёт задания будущих глав и повторно решённые.
2. **[Состояние: открыт «X» (стр. N–M); решено a/b, осталось qN…]** — хвост КАЖДОГО ответа инструмента;
   промпт велит сверяться с ним и называть страницы вслух («открой на страницах 4–5»). Рассинхрон закрыт.
