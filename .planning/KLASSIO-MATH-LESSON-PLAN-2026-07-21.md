# Площадь и периметр прямоугольника — две независимые величины (ХАБ-Анимус, античные миры)

> **Класс:** 3–5 кл (ядро 4 класс), дети 9–13 · **Длительность:** 18–22 мин · **Модель:** choice — Аня спрашивает голосом → ребёнок ВЫБИРАЕТ на экране → мир РАЗЫГРЫВАЕТ выбор.
> **Источник:** дизайн-панель 2026-07-21 (wf_b18b16b0-bd3). Это спек под board-компонент (рисуется в Claude Design) + боевой контракт `window.__klassioEngine`.

## Аня — учитель-робот

Аня-РОБОТ: тёплая, любопытная спутница-исследователь, НЕ «учитель у доски». Короткие фразы для 9–13, без терминов «изопериметрия»/«независимые переменные» — только «порознь», «на замке», «гуляет», «забор/пол/сад». Робот-фрейминг («губами не шевелю — я же робот, зато вижу насквозь») звучит ОДИН раз в hub-start и больше не педалируется. Хвалит КОНКРЕТНО, называя числа, которые ребёнок только что доказал (никакого пустого «молодец»). Голос Yandex TTS (alena/julia). ЖЁСТКОЕ правило петли: спросила → ЗАМОЛЧАЛА, пока ребёнок думает (реплики-паузы «я подожду» — таймер ожидания, НЕ отправлять в TTS, не talk-over) → мир разыграл выбор → только тогда реагирует. Никаких подсказок до выбора. При ошибке — переобъясняет ДРУГОЙ картинкой, а не «краснеет галочка», тон срочный-но-тёплый, на стороне ребёнка («перестроимся»), без укора.

## Контракт доски (интерфейс board-компонента)

**Пропсы — что 3D/учитель ШЛЁТ доске:**
- phase: 'intro' | 'task' | 'record' | 'law' — определяет режим доски (гипотеза без штрафа / боевая задача / запись формулы / финальный закон)
- stageId: string — стабильный id шага (temple-area-stilobat, garden-square, castrum-siege…) для ЛК/аналитики
- boardTitle: string — заголовок карточки на доске
- law: string — короткая формулировка закона/подсказки под доской (не обязателен на intro)
- question: string — точный текст вопроса, который Аня задала голосом
- options: Array<{ id:string, label:string, correct:boolean }> — 2–4 варианта; порядок как в плане, correct прошит
- a: number, b: number — стороны текущего прямоугольника (6×4, 5×3, 1×11, 6×6, 1×36…); доска строит сетку a×b
- lock: 'P' | 'S' | null — какая величина «на замке» (сад → 'P'=24; лагерь → 'S'=36; храм/хаб → null)
- lockValue: number | null — значение запертой величины для табло-замка (24 или 36)
- planView: enum — режим вида сверху (см. planViewModes): 'grid-fill' | 'perimeter-walk' | 'dual-scoreboard' | 'shape-morph' | 'form-row-chart' | 'formula-record' | 'stilobat-empty'
- sCounter: { target:number, show:boolean } — цель тикающего счётчика площади и надо ли его показывать
- pCounter: { target:number, show:boolean } — цель счётчика периметра / шагов обхода / кольев
- morphFrom?: {a,b}, morphTo?: {a,b} — пара форм для GSAP-морфа при неизменном числе клеток (1×11↔6×6, 1×36↔6×6, 3×9→6×6)
- consequenceCorrect: string — что доска РАЗЫГРЫВАЕТ при верном (staggered-заливка, обводка-кольцо, защёлк табло, знак ≠, зелёная печать)
- consequenceWrong: { byOptionId: Record<string,string> } — что доска показывает при КАЖДОМ неверном варианте (пустая серединка, брешь, глитч-слияние, откат числа) — привязано к конкретному дистрактору
- reduceMotion: boolean — уважать prefers-reduced-motion: морфы/тряска/глитч приглушаются, суть остаётся

**События — что доска шлёт НАЗАД:**
- onSelect(optionId) → доска шлёт учителю выбранный вариант (до разыгрывания) для остановки TTS/паузы
- onSolve(stageId, optionId) → верный выбор: доска отыграла последствие, готова к следующему шагу (боевой __klassioEngine ждёт этот колбэк как onSolve)
- onWrong(stageId, optionId) → неверный выбор: доска отыграла ОБРАТИМУЮ поломку, вернулась в исходное, тот же вопрос активен снова (__klassioEngine onWrong)
- onConsequenceDone(stageId, kind:'correct'|'wrong') → анимация-последствие доиграла — сигнал учителю, что можно давать реплику-реакцию Ани (анти-talk-over)
- onRequestNext(stageId) → доска просит следующий шаг после успешного onSolve + реплики Ани (двигает сквозную нумерацию 1→13)
- onReplay(stageId) → ребёнок повторно смотрит разыгранное последствие (без смены состояния прогресса)

**Режимы вида сверху (planView):**
- stilobat-empty — пустая сетка-заполнение a×b с приглушёнными точками-колоннами по краю (старт задачи на площадь)
- grid-fill — staggered-заливка плиток волной из угла + тикающий счётчик S (площадь)
- perimeter-walk — обегающая линия по краю со счётчиком по сторонам / вбиванием кольев «тк-тк-тк» (периметр)
- dual-scoreboard — двойное табло «одно на замке 🔒 — другое гуляет»: сад P=24🔒/S тикает, лагерь S=36🔒/P тикает, храм-климакс S=24 ≠ P=20
- shape-morph — плавный GSAP-морф формы при неизменном числе клеток (1×11↔6×6, 1×36↔6×6, 3×9→6×6), контур-верёвка/периметр той же длины
- form-row-chart — ряд миниатюр всех форм со столбиками величины (сад: S 11…36 растёт к квадрату; лагерь: P 74…24 убывает к квадрату)
- formula-record — чистая доска-ХАБ: формулы S=a×b и P=2(a+b) с подписями «пол»/«край», мини-эталон 1×1 (орган записи)

## Сценарий урока — 13 шагов

### Шаг 1 · 🚪 ВСТУПЛЕНИЕ — Забор или пол — одно число или два?

**Пространство:** ХАБ «Мастерская мерок» — белое нейтральное пространство-симулятор three.js. Ребёнок сидит, вертит камерой. Парящая доска по центру, Аня-робот рядом.

**Аня (голос):**
> Привет. Я Аня — твоя спутница по этой лаборатории.
> Губами я не шевелю. Я же робот. Зато вижу насквозь.
> Смотри на доску: забор ВОКРУГ и пол ВНУТРИ. Это одно число или два?
> Скажи, что думаешь. Потом проверим по-настоящему.

**Вид сверху на доске:** Пустая доска-ХАБ: контур прямоугольника из эталонных клеток 1×1, одна клетка подписана «1 метр»; сверху два пустых окна-табло «S = ?» и «P = ?».

**Вопрос:** Забор по краю и пол внутри — это одно число или два разных?

**Варианты:**
- ✅ Два разных числа
- ◻️ Одно число — место же одно
- ◻️ Числа всегда одинаковые

**✔ Верно →** МИР не награждает бурно — это ещё гипотеза. Загораются два пустых табло [S ?] [P ?]. Обратный отсчёт 3-2-1 — из белого пола ХАБа поднимается мраморный храм, мир СОБИРАЕТСЯ вокруг сидящего ребёнка. Аня: «Так и проверим».

**✘ Неверно →** МИР НЕ ЛОМАЕТСЯ (гипотеза, не факт). Аня спокойно: «Может быть. Давай построим настоящее место и посчитаем — тогда увидим сами». Тот же отсчёт, храм собирается. Оба табло остаются пустыми — их заполнит следующий мир, а не красная галочка.

### Шаг 2 · 🎯 ЗАДАНИЕ — Пол храма — сколько плит?

**Пространство:** АНТИЧНЫЙ ХРАМ (герой-эпизод, зодчество). Мир собрался вокруг: под ногами мраморный стилобат 6×4, размеченный на плиты 1×1 (6 в ряд, 4 ряда), по краю — пустые основания колонн, вдали фронтон и голубое эгейское небо. Аня-робот стоит на полу и обводит его рукой (ДЕМОНСТРИРУЕТ до вопроса).

**Математика/закон:** Площадь = пол ВНУТРИ: считаем, сколько клеток-плиток закрывают всю поверхность. S = a × b.

**Аня (голос):**
> Смотри — белое пространство собралось в храм. Мы стоим на его каменном полу.
> Строители зовут этот пол стилобат. Его надо выложить мраморными плитами.
> Каждая плита — ровно метр на метр. Одна клетка сетки.
> Сколько плит нужно, чтобы закрыть ВЕСЬ пол — до последнего уголка?

**Вид сверху на доске:** Вид сверху: прямоугольник-сетка 6×4 = 24 пустых квадрата-плиты. Подписи сторон 6 м и 4 м. По краю приглушённые точки-основания колонн. Счётчик S пустой, мигает под сеткой.

**Вопрос:** Сколько мраморных плит 1×1 закроют весь пол храма 6 на 4?

**Варианты:**
- ✅ 24 плиты
- ◻️ 20 плит
- ◻️ 10 плит
- ◻️ 16 плит

**✔ Верно →** МИР: 24 плиты влетают волной из угла (staggered), счётчик тикает 1→24, пол вспыхивает золотисто-мраморным, Аня подпрыгивает. ДОСКА: сетка заполняется цветом, в картуше «ПЛОЩАДЬ» ставится S = 24 (= 6×4). Аня: «Весь пол — наш, до последней клетки!»

**✘ Неверно →** 20 = посчитал ЗАБОР вместо ПОЛА; 10 = сложил стороны 6+4; 16 = только край, забыл внутренние. МИР: плиты заполняют лишь КОЛЬЦО по краю, середина пустая, чёрные дыры, одна плита с эхом проваливается. ДОСКА подсвечивает пустую серединку. Аня ДРУГОЙ картинкой: «Ты закрыл только края. А пол — это ВСЁ внутри, каждая клеточка. Зальём ряд за рядом и пересчитаем». Плиты обратимо поднимаются, выбор снова.

### Шаг 3 · 🎯 ЗАДАНИЕ — Обход по колоннаде — сколько метров?

**Пространство:** АНТИЧНЫЙ ХРАМ. Пол уложен и держится (S=24 горит на табло). По КРАЮ платформы вырастает колоннада вдоль всех 4 стен. Аня-робот ДЕМОНСТРИРУЕТ ПЕРЕД вопросом: медленно обходит храм пешком вдоль колонн, оставляя светящиеся следы-шаги, проговаривая стороны. Внутренний пол приглушён.

**Математика/закон:** Периметр = ЗАБОР по краю: длина всего обхода границы. P = 2 × (a + b).

**Аня (голос):**
> Пол готов. Теперь я обойду храм по краю, вдоль колонн — смотри за мной, я иду ногами.
> Шесть метров… поворот… четыре… снова шесть… и снова четыре — и я вернулась в начало.
> Это обход по самой границе. Забор по краю храма.
> Сосчитай мой путь: сколько всего метров я прошла ВОКРУГ?

**Вид сверху на доске:** Тот же прямоугольник 6×4, ярко подсвечена ГРАНИЦА: колонны-точки по всему краю, стрелка обхода идёт по кругу 6→4→6→4. Пол внутри затемнён. Стороны подписаны 6, 4, 6, 4. Счётчик P пустой; S=24 уже горит в своём картуше.

**Вопрос:** Аня обошла храм по краю: 6, потом 4, потом 6, потом 4. Сколько метров всего?

**Варианты:**
- ✅ 20 метров
- ◻️ 24 метра
- ◻️ 10 метров
- ◻️ 40 метров

**✔ Верно →** МИР: Аня замыкает круг ровно на 20-м шаге, следы вспыхивают сплошным кольцом, все колонны встают разом — колоннада «защёлкивается» со щелчком. ДОСКА: граница обведена, в картуше «ПЕРИМЕТР» ставится P = 20 (= 2×(6+4)), счётчик дотикивает до 20. Аня: «Ровно двадцать шагов по кругу!»

**✘ Неверно →** 24 = взял ПОЛ вместо ОБХОДА; 10 = обошёл 2 стороны; 40 = каждую сторону дважды. Выбрал 24 — МИР: колонны лезут на КАЖДУЮ клетку пола (24 шт), храм превращается в частокол, Аня утыкается в колонну посреди зала: «Стой! Колонны — только по КРАЮ. Внутри пол — это обход». Лишние тонут, остаётся 20. Выбрал 10 — Аня упирается в обрыв, дальней колоннады нет, свистит ветер: «Я прошла лишь две стены — а их четыре. Обойди ВСЕ». Недостающие стороны проявляются. Мир ждёт нового выбора.

### Шаг 4 · 🎯 ЗАДАНИЕ — Одно место — два числа. Кто есть кто?

**Пространство:** АНТИЧНЫЙ ХРАМ — кульминация расщепления. Храм достроен, на ДВОЙНОМ табло у одного храма горят сразу два числа: пол S=24, колоннада P=20. Аня-робот встаёт на границу «пол↔край» и показывает рукой то ВНИЗ (заполненный пол), то ВОКРУГ (обход).

**Математика/закон:** У ОДНОГО прямоугольника две РАЗНЫЕ величины: площадь (пол внутри, S=24) и периметр (обход по краю, P=20). Живут порознь, НЕ обязаны совпадать: S=24 ≠ P=20.

**Аня (голос):**
> Смотри, что вышло. Храм ОДИН — а чисел получилось ДВА.
> Пол я ЗАПОЛНИЛА клетками: их двадцать четыре.
> Край я ОБОШЛА шагами: их двадцать.
> 24 и 20 — разные. И это правильно! Вопрос: где какое число?

**Вид сверху на доске:** Двойное табло на одном прямоугольнике 6×4. Слева он ЗАЛИТ (24 клетки, ярлык «пол · площадь · S=24»); справа у того же прямоугольника обведён только КРАЙ (20 м, ярлык «забор · периметр · P=20»). Между картинками крупный знак ≠. Два счётчика: S=24, P=20.

**Вопрос:** У одного храма 6×4 вышло два числа: 24 и 20. Что верно?

**Варианты:**
- ✅ 24 — это пол (площадь), а 20 — обход по краю (периметр)
- ◻️ 24 — это обход, а 20 — это пол
- ◻️ 24 и 20 должны стать одним числом — я где-то ошибся
- ◻️ У прямоугольника бывает только одно число

**✔ Верно →** МИР: оба табло на замок — пол вспыхивает золотом (24), колоннада светом (20), между ними знак ≠. Сквозь колонны встаёт солнце, с фронтона спускается лавровый венок. ДОСКА фиксирует: S=24 ≠ P=20 у ОДНОГО храма. По АРКЕ мир начинает растворяться обратно в белый ХАБ. Аня: «Пол и забор — порознь. Никогда их не равняй».

**✘ Неверно →** «Должны совпасть/одно число» = ГЛАВНЫЙ миф урока. МИР: два табло пытаются слиться, храм ГЛИТЧИТ — пол и колоннада наползают, мрамор рябит, гул землетрясения, колонны кренятся. Аня спокойно раздвигает пол и край в две отдельные светящиеся панели: «Пол я ЗАПОЛНЯЮ — клеток 24. Край я ОБХОЖУ — шагов 20. Два разных дела, и числа разные, так и надо». Мир стабилизируется. «Поменял местами» — Аня прокатывает по очереди заливку (24) и обход (20), подписывая, что откуда. Ждём выбора.

### Шаг 5 · ✍️ ЗАПИСЬ — Две формулы порознь

**Пространство:** ХАБ «Мастерская мерок» — храм растаял, вернулись в белое. Парящая доска, Аня-робот. ОРГАН ЗАПИСИ: закрепляем формулы.

**Математика/закон:** S = a × b (пол) · P = 2 × (a + b) (край) — две записи, две величины.

**Аня (голос):**
> Храм растаял. Мы снова в белой мастерской.
> Оставим главное — на доске. Две записи, две величины.
> Где формула про ПОЛ, про площадь?

**Вид сверху на доске:** Чистая доска-ХАБ: две формулы столбиком S = a × b и P = 2·(a+b), под каждой подпись «пол» / «край», рядом мини-сетка-эталон 1×1.

**Вопрос:** Какая запись — про площадь (про пол внутри)?

**Варианты:**
- ✅ S = a × b
- ◻️ P = 2 × (a + b)
- ◻️ a + b

**✔ Верно →** МИР: на доске рядом ложатся две строки S = a × b и P = 2·(a+b), у первой подсвечивается слово «площадь». Аня: «Вот они, порознь. a и b — стороны. Запомним и проверим на новом прямоугольнике».

**✘ Неверно →** P = про забор; a+b = просто сумма. МИР: у формул зажигаются подписи «пол» и «край», чтобы видна была разница. Аня: «Это забор, периметр — две длины и две ширины. А площадь — стороны УМНОЖИТЬ». Повтор.

### Шаг 6 · 🎯 ЗАДАНИЕ — Дрилл: посчитай обе — 5×3

**Пространство:** ХАБ — мини-дрилл на новом прямоугольнике 5×3, обе величины сразу. Закрепление перед сменой миров.

**Математика/закон:** У любого прямоугольника S и P считаем ОТДЕЛЬНО.

**Аня (голос):**
> Новый прямоугольник: 5 в длину, 3 в ширину.
> Посчитай обе величины сразу — и пол, и забор.
> Я молчу, думай спокойно.

**Вид сверху на доске:** Сетка 5×3: слева заливка 15 клеток (S), справа обводка края (P); два окна S=?, P=? заполняются по очереди.

**Вопрос:** Прямоугольник 5×3. Чему равны площадь S и периметр P?

**Варианты:**
- ✅ S = 15, P = 16
- ◻️ S = 15, P = 15
- ◻️ S = 8, P = 16
- ◻️ S = 16, P = 15

**✔ Верно →** МИР: на сетке 5×3 сначала заливаются 15 клеток (счётчик S=15), затем синяя обводка по краю (P=16). Оба окна доски зажигаются. Аня: «Пятнадцать и шестнадцать. Разные числа у одного прямоугольника — уже не путаешь».

**✘ Неверно →** S=15,P=15 = приравнял P к S («растут вместе»); S=8 = сумма 5+3 вместо умножения; S=16,P=15 = перепутал местами. Парад-награда: конфетти, орёл легиона, оливковая ветвь, золотая аквила с лавром. Аня хвалит КОНКРЕТНО: «Ты не купился на ловушку: та же верёвка 24 — сад от 11 до 36; те же 36 палаток — стена от 24 до 74. Одно на замке — другое гуляет. Это ты доказал сам».

**✘ Неверно →** «Одно/вместе» = старт-миф, теперь опровергнут. МИР: оба мира-трофея разом показывают контрпример — сад 1×11 и 6×6 с одной верёвкой мигают рядом; лагерь 1×36 и 6×6 с теми же 36 палатками. Аня: «Смотри ещё раз: забор одинаковый — а внутри РАЗНОЕ. Значит числа два, и живут они порознь». Повтор, затем парад.

## Вау-моменты (эмоциональные пики)

- ХРАМ, кульминация (шаг 4): у ОДНОГО храма на двойном табло горят сразу S=24 и P=20 с крупным ≠ между ними — стержень урока «одно место — два числа» виден глазом; при мифе «должны совпасть» храм ГЛИТЧИТ (пол и колоннада наползают, мрамор рябит, гул землетрясения) и обратимо расходится в две светящиеся панели.
- САД (шаг 8): та же золотая верёвка морфит из тонкой ленты 1×11 в квадрат 6×6, счётчик S ползёт 11→36 при неподвижном P=24🔒 — «та же верёвка, а сада ВТРОЕ больше»; при ошибке лента строится реально пустой (11 олив + сухая потрескавшаяся земля, саженцы остаются в корзине).
- ЛАГЕРЬ (шаг 12): висцеральная гонка на закате — запас 24 кола подобран так, что ТОЛЬКО квадрат смыкается впритык; при 1×36 счётчик замирает на 24, красная брешь в 50 шагов, чужой рог и факелы через реку, край экрана темнеет — затем мир отматывает пролом назад (тревога через звук, без жестокости).
- МОСТ ДВУХ МИРОВ (шаг 13): каллбэк «один и тот же квадрат 6×6 — герой обеих историй»: в саду вместил БОЛЬШЕ всего земли (max S при фикс. P), в лагере просит МЕНЬШЕ всего забора (min P при фикс. S). Оба эпизода сходятся на 6×6 — главная эмоциональная и математическая рифма урока.
- АРКА АНИМУСА: castrum ВТЯГИВАЕТСЯ в доску (0.85 с, easeOutQuint, НЕ реверс сборки) → белый ХАБ → доска сама пишет закон → мир возвращается наградой (аквила + лавр) — рычаг внимания замыкается.
- Первая реплика Ани-робота: «Губами я не шевелю. Я же робот. Зато вижу насквозь» — снимает неловкость липсинка и сразу задаёт тёплый исследовательский тон (звучит ОДИН раз, в hub-start).
