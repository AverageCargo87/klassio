# ПЛАН ГОТОВНОСТИ: «Сайт» → тест на людях с Авито

Синтез 5 аудитов рабочего дерева `edu-platform-test`. Целевой формат теста (из Аудита 5): **модерируемые сессии, 6–8 семей, урок astronom, десктоп/ноутбук, ребёнок 9–11 лет + родитель, оплата 2000 ₽ по СБП**. Все не-модерируемые сценарии («сам дома по ссылке») — вне скоупа первой итерации, это снимает половину хвостов.

**Ключевое продуктовое решение, которое надо принять в День 1 (полчаса, но блокирует всё):** какой стек — основной для теста. Дефолт кода сейчас `sber` (`app/tutor/[subject]/[slug]/page.tsx:26`), решение по памяти проекта — «остаёмся на 11labs», а 152-ФЗ чище у Sber (голос ребёнка не уходит иностранному процессору). Рекомендация: **основной = 11labs (это продукт, который валидируем), Sber = fallback-ссылка у модератора; ссылки тестерам всегда с явным `?stack=`, трансграничная обработка вписывается в согласие и политику.** Дальше план исходит из этого.

Vercel к git не привязан — деплой только руками.

## 3. P1 — Без этого тест даст мусорные данные

1. **Баг seq-транскрипта** — `seqRef` с 0 на маунт + resume того же sessionId + onConflictDoNothing = реплики после перезагрузки молча выбрасываются (`use-transcript-logger.ts:18`, `lib/tutor/sessions.ts:47-78`, `transcript.ts:44`). Инициализировать seq из `max(seq)+1`. **0.5 дня.**
2. **Телеметрия сбоев и латентности в БД** — `[latency:turn]` сейчас в console.log и теряется (`tutor-lesson.tsx:383`); события `mic_denied`/`ws_disconnected`/`voice_connect_failed` + перцентили латентности батчем в payload `session_completed` — ручка `/api/tutor/event` уже есть. Плюс `window.onerror` туда же (или Sentry, если успеем). **1 день.**
3. **Помечание `abandoned`** — статус есть в enum (`schema.ts:147`), не ставится никем; скрипт/cron «in_progress старше N часов → abandoned». Иначе на вопрос «сколько дошли до конца» ответа не будет. **2 часа.**
4. **SQL-ноутбук/скрипт кросс-юзер метрик** — completion, длительность, attempts, «не поняла»-счётчик из `lesson_transcript` (`scripts/analyze-transcript-metrics.mjs`). Кабинет только per-parent, агрегатов нет вообще. **0.5 дня.**
5. **Бэкпорт фиксов из Sber-клона в 11labs-путь** — `BOARD_MIN_MS` 60с→25с (известный рассинхрон «речь о новом, доска старая», `tutor-lesson.tsx:75` vs `tutor-lesson-ru.tsx:49-53`) + тул-ответы без технических id досок (`tutor-lesson.tsx:261,280`). **0.5 дня.**
6. **Uptime-монитор VPS** — бесплатный пингер на оба healthz + TG-алерт; VPS — тройной SPOF (оба стека + nip.io), рестарт убивает все идущие уроки. **1 час.**
7. **Операционные артефакты теста** — объявление (вариант А «Авито Услуги → Репетиторы» + Б в TG-чаты), скрининг-анкета, чеклист модератора, опросник родителя, 5 вопросов ребёнку — всё уже написано в Аудите 5, осталось завести TG для заявок и календарь слотов. **0.5 дня.**
8. **Гигиена данных** — флаг/отсев дев-сессий (локальный дев пишет в ту же Neon; 7 строк tutor_session уже мусорные) — хотя бы список «своих» userId в скрипте метрик. **1 час.**
9. **Модерация: убрать блеф** — баннер «Уведомление отправлено родителям» при том, что notifyParent реально ничего не шлёт; на модерируемом тесте родитель сидит рядом и это вскроет. Либо реальное письмо через уже подключённый Resend, либо смягчить формулировку. **2 часа.**
10. **childName в шапке кабинета** — сейчас всегда «Учёба ребёнка» (`app/cabinet/page.tsx:14` vs `lib/auth/config-options.ts:50-55`); мелочь, но для родителя это первый экран «продукт про моего ребёнка». **2 часа.**
11. **Убрать `[latency:*]` console.log из прода** — палит кухню перед родителем, сидящим рядом. **15 мин.**

**Итого P1: ~3 дня.**

## 4. P2 — Явно НЕ делать сейчас

- **Лендинг/маркетинговый сайт** — 3 абзацев на `/login` достаточно; тестеры приходят по прямой ссылке после скрининга.
- **Форма саморегистрации** — при 6–8 модерируемых сессиях create-user руками быстрее.
- **Полный мобильный адаптив урока** — гейт «только компьютер» + скрининг закрывают; адаптив — после того как узнаем, нужен ли продукт вообще.
- **Генерация домашки** — мёртвая ветка (`createHomework` не вызывает никто); секция в ЛК будет пустой — ок, спросим про домашку словами в опроснике.
- **Продуктовая веб-аналитика (PostHog/Метрика)** — на 6 модерируемых сессиях воронку заменяет наблюдение модератора; Метрика — 30 мин, можно в P1 «если останется время», не раньше.
- **Полноценный реконнект в ту же LLM-сессию / персист прогресса канваса** — дорогая инженерия; на модерируемом тесте обрыв закрывается баннером + модератором.
- **Rate-limit, отдельная БД, log drain, честный реконнект после рестарта VPS, синхронизация nginx-доков с хостом `.151`** — правильные вещи для масштаба >30 юзеров, не для 8 сессий.
- **Оферта, договор ГПХ** — оплата физлицо→физлицо по СБП, на этой стадии достаточно.
- **Miro-шелл и 3D** — не показываем тестерам вообще; тестируем один канонический вид «Сайт».
- **Расширенная модерация (селф-харм словарь)** — тест модерируемый, взрослый рядом; в бэклог перед не-модерируемым этапом.

## 7. Риски (топ-5)

| # | Риск | Митигация |
|---|---|---|
| 1 | **Тихий мусор вместо данных**: не выкачен какой-то фикс/env — тестеры получают чужого агента, sber вместо 11labs, localhost-оркестратор; статистика неинтерпретируема | Смоук-чеклист перед КАЖДЫМ днём сессий: чистый браузер, ссылка с явным `?stack=`, голос отвечает, транскрипт пишется в Neon (SQL-проверка). Фолбэк-агент заменён на явную ошибку, не warn в логе |

| 3 | **Юр-хвост**: сессия прошла без подписанного согласия / согласие без пункта про голос и иностранные сервисы | Жёсткое правило чеклиста: нет скана подписи за 24 ч до слота — сессии нет; пункт про запись проговаривается на видеозаписи созвона; РКН-уведомление подано заранее |
