# Klassio — режимы отображения урока: подробное описание вариантов

Обсуждение 2026-06-23 (ветка edu-platform-test). Связано: `klassio-display-modes-control-law` (память), `.planning/KLASSIO-LESSON-CANVAS-CONTRACT.md`, спайк `.tmp/spikes/3d-classroom/`.

**Общее для всех вариантов.** Показывают ОДИН и тот же урок через общий контракт канваса (`__klassioEngine.showBoard/showTask`, голос Ани 11labs, RU). Различие — только «оболочка» вокруг канваса. Урок-эталон для примеров: **«Мир глазами астронома»** (Окружающий мир, 4 класс), доски по порядку: `cover → etymology → bodies → solar → sunEarth → facts → reward`.

**Закон над всеми режимами:** Аня ведёт камеру; у ученика НЕТ свободы перемещения. Агентность ученика только над объектом урока: ответить на задачу, крутить вынесенный Аней объект, тапнуть туда, куда она зовёт. Ходить/летать/листать мир самому — нельзя.

**Тех-лимит:** браузер рисует DOM поверх WebGL → в любом 3D живая доска остаётся плоским iframe. 3D = окружение вокруг канваса, не сам интерактивный канвас.

## A · Кино-сайт (Сайт 2.0)

**Суть:** то, что уже есть, поднятое до уровня Apple-кейноута. Плоский 2D, но ощущается дорого и живо.

**Вход / первый экран:** тёмный полноэкранный канвас (глубокий космос/градиент в фирменной палитре Klassio), по центру мягко пульсирует аватар Ани + одна кнопка «Начать урок». Ничего лишнего — пустой канвас из нового видения. Нажал → кнопка растворяется, Аня здоровается голосом.

**Как выглядит:**
- Фон живой: медленно «дышащая» аврора/звёздное поле, которое **реагирует на голос Ани** (audio-reactive — на её речи лёгкая пульсация и частицы). Подсознательно «она здесь, живая».
- Доски не перелистываются, а **влетают киношно** (GSAP): заголовок набирается по буквам, картинки выезжают с параллаксом, прошлая доска уходит в глубину/блюр.
- Крупная типографика, много воздуха, скругления, мягкие тени, 1–2 акцентных цвета.
- Аватар Ани выразительный (Lottie/риг), не статичная картинка: слушает (покачивание), говорит (липсинк), думает (точки), радуется верному ответу.

**Где что на экране:** Аня — компактный «пузырь» внизу-центре или в углу; доска — основная сцена; тренажёр выезжает карточкой поверх доски; реплики — минималистичные субтитры под Аней (опц.).

**Урок 1 по шагам:** пустой канвас → «Начать» → Аня: «Привет, я Аня. Как настроение?» (smalltalk, фон чуть теплеет) → пара вплетённых вопросов на уровень → `cover` влетает заголовок «Мир глазами астронома» → `etymology` (что значит «астроном») → микроцикл теория→задача: текст на доске → карточка-выбор поверх → верно: частицы + похвала (`onSolve`) → дальше `bodies/solar/sunEarth/facts` → `reward`: экран «урок пройден» с салютом.

**Взаимодействие ученика:** только ответы в тренажёре (тап варианта / ввод) + опц. клик по интерактивному элементу доски, когда Аня приглашает (`onPlanetClick`). Никакой навигации.

**Вау-вставки:** L1 (3D-планета поверх доски) и L2 (панорамный фон) включаются здесь же по слову Ани.

**Плюсы/минусы:** дёшево (2D/canvas/GSAP), летает на слабых, контент-агностик (любой урок без переделки), низкий риск, быстрый результат. Минус — это «улучшение знакомого», слабее эффект новизны «вау».

## B · Карта-путешествие (фаворит)

**Суть:** урок — маршрут по тематическому миру-карте. Из Миро взяли раскладку + зум-в-фокус, но НЕ свободу: камера на рельсах, Аня за рулём.

**Вход / первый экран:** камера в космосе, перед глазами стилизованная **звёздная карта маршрута** урока: пунктир-тропа со «станциями» (каждая станция = доска). Видно весь путь и сколько впереди — как уровни в игре. Аватар Ани рядом, кнопка «Отправиться».

**Как выглядит:**
- Большой пространственный холст (всё ещё 2D — параллакс-слои, не WebGL): глубина за счёт слоёв звёзд.
- Каждая станция — иконка-точка на тропе: пройденные подсвечены, текущая пульсирует, будущие приглушены.
- **Камера choreographed:** когда Аня переходит к теме, камера сама плавно подлетает/зумит к следующей станции (ease, разгон-торможение) и раскрывает её доску на весь экран. Ребёнок — пассажир, камеру не ведёт.
- Между станциями короткий «пролёт» (~1–1.5с) с параллаксом — ощущение движения вперёд.

**Где что:** на станции раскрывается доска (как в A); тренажёр — карточка поверх; мини-карта прогресса ужимается в уголок («ты здесь»); Аня — компаньон-голос + аватар.

**Урок 1 по шагам:** карта из 6 станций → «Отправиться» → камера к станции 1 (`cover`), Аня здоровается/smalltalk → станция 2 (`etymology`) теория + задача → пролёт к станции 3 (`bodies`) → станция 4 (`solar`) раскрывается в интерактивную карту Солнечной системы (клик по планете → `onPlanetClick`, Аня комментирует) → `sunEarth`, `facts` → финал = `reward`, по тропе салют «маршрут пройден».

**Взаимодействие ученика:** ответы в тренажёре + тап по объекту, когда Аня зовёт. Перемещение по маршруту — только вперёд и только рукой Ани; назад/в сторону сам не уходит (фокус).

**Вау-вставки:** L1 особенно естественен (на станции «Солнечная система» планета вылетает 3D — крутить); L2 — задник станции меняется под тему.

**Плюсы/минусы:** лучший баланс вовлечение × цена × польза. Приключение и ощущение прогресса (геймификация без мишуры), пространственная память. Всё ещё 2D — дёшево, тот же движок. Минус — больше работы над картой/камерой/переходами, чем в A; нужна аккуратная режиссура камеры.

## C · Класс-мир (лобби / премиум) — два под-вкуса

**Суть:** место, куда «попадаешь». Максимум атмосферы и presence. Роль — первое впечатление/онбординг, НЕ ежедневная петля. Доска внутри всё равно 2D-iframe.

**C1 · 3D-комната:**
- Вход: красивый процедурный класс (спайк уже есть) — солнечный кабинет, парты, окна, доска на стене. Камера фиксирована «за партой ученика», смотрит на доску (никакого WASD).
- Аня встречает «в классе» (smalltalk в антураже кабинета), потом доска на стене оживает уроком.
- Выглядит: тёплый свет, мягкие тени, низкополигональный уют; на партах тематические пропсы (планеты), по клику инфо-карточка.
- Минус: тяжелее на слабых (тени/материалы), per-lesson нужна сцена; интерактив всё равно на 2D-доске.

**C2 · 360°-панорама (дешевле, не менее вау):**
- Вход: «телепорт» внутрь AI-сгенерированной 360°-панорамы (космос / поверхность Луны / обсерватория). Крутишь головой (look-around), но **не ходишь**.
- Доска и объекты висят перед панорамным задником.
- Выглядит максимально «вау с порога», дёшево относительно полноценного 3D (одна сфера-картинка на сцену). Осмотр панорамы — только в smalltalk/паузах; на задаче камера залочена на доску.
- Минус: завязан на генерацию фонов; глубины меньше, чем у настоящего 3D.

**Урок 1:** вход в класс/панораму → Аня в атмосфере здоровается → доска на стене/перед тобой ведёт те же 6 досок и задачи → `reward` в антураже места.

**Взаимодействие:** ответы + клик по приглашённому объекту. Камера фиксирована (C1) или только поворот (C2). Никакой ходьбы — ровно запрет на свободу перемещения.

## L1 · Слой-вау: 3D-объекты по требованию (`showObject`)

**Суть:** не режим, а инструмент. Аня словом вызывает гладкую интерактивную 3D-модель прямо в текущей оболочке.

**Как выглядит:** по команде модель **вылетает поверх доски** (планета, связка Земля-Луна, сердце, молекула, многогранник) на стеклянной «полке» в стиле visionOS — матовое стекло, мягкое гало, парит. Ребёнок **крутит её пальцем/мышью с инерцией**, можно зум. Аня комментирует то, что он рассматривает.

**Почему берём (по закону):** агентность над ОБЪЕКТОМ урока (крутить планету на месте), а не над перемещением — вовлекает, не отвлекает.

**Где работает:** в A, B и C одинаково (строится один раз). Технически — отдельный WebGL-слой поверх 2D, появляется/прячется по `showObject`.

**Стоимость:** нужна 3D-модель на объект (готовые glTF-ассеты). Точечно, только где контент реально 3D.

## L2 · Слой-вау: панорамный фон 360°

**Суть:** сменный AI-задник для любой 2D-оболочки. Урок про вулканы → фон «внутри вулкана»; про космос → орбита/звёздное поле.

**Как выглядит:** позади доски/Ани — глубокий 360°-фон (или его кусок с параллаксом). В A/B даёт «место» без полноценного 3D; в C2 — это и есть оболочка.

**Взаимодействие:** осмотр только в smalltalk/переходах; на задаче залочен, чтобы не тянул внимание.

**Стоимость:** генерация панорам (Blockade/GigaChat). Дёшево добавляет атмосферу.
