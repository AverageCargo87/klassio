# Конкуренты и референсы: кто ещё делает ИИ-уроки

> Собрано 09.09.2026 пятью параллельными агентами (WebSearch), без глубокого анализа —
> название, что это, ключевая фишка относительно Klassio. Детальный разбор — отдельным
> кругом, если решим, что кто-то из списка достоин.

Klassio для сравнения: ИИ-аватар (озвученный видео-учитель) читает урок по учебнику
вслух, ребёнок отвечает ГОЛОСОМ, идёт тест и разбор — весь урок целиком, по сценарию.

## Ближе всего к нашей механике (голос + аватар/диалог + ведёт САМ)

- **eSelf** — https://www.eself.ai — интерактивный ИИ-аватар-репетитор, первый в мире
  гострольный запуск на всю страну (Израиль, математика и иврит). Ультра-низкая
  задержка, многоязычность, адаптация под сильные/слабые стороны ученика. Самый прямой
  аналог из всех найденных.
- **Tavus** — https://www.tavus.io — не готовые ролики, а real-time «Conversational
  Video Interface»: цифровой человек слышит и отвечает голосом+видео с задержкой ~1 с.
  Технологически ближе всего к нашему стеку (мы тоже realtime, не префаб-видео).
- **Amira Learning** — https://amiralearning.com — мультяшный аватар СЛУШАЕТ, как
  ребёнок читает вслух, поправляет в реальном времени (обучен на 10+ млрд слов детской
  речи). Обратный процесс к нашему — не озвучивает, а слушает. 1800+ школьных округов
  США, ~$20/год на ученика.
- **Khanmigo** (Khan Academy) — https://www.khanmigo.ai — голосовой режим (TTS+STT),
  сократовский метод (наводит вопросами, не даёт готовый ответ). Бесплатен для учителей
  в 44+ странах при поддержке Microsoft.
- **Duolingo Max** (Video Call / Roleplay) — https://www.duolingo.com — «видеозвонок» с
  персонажем Lily, живой голосовой диалог с памятью прошлых разговоров.
- **Speak** — https://www.speak.com — voice-first языковой репетитор на моделях OpenAI,
  $162M финансирования, оценка $1B. Весь курс построен вокруг устного ответа с первого
  урока.

## Биг-тех: показы и встроенные ИИ-инструменты для учёбы

- **Google LearnLM / Guided Learning** (в Gemini) — модель на принципах педагогики,
  сократовский чат-репетитор, без голосового аватара.
- **Google Learn About** — https://learning.google.com/experiments/learn-about —
  генерирует «учебниковый» разбор темы на лету с картинками и меню подтем. Без голоса
  и без структуры целого урока с проверкой.
- **Google NotebookLM — Audio Overviews** — загрузил материалы → ИИ генерирует
  10–20-минутный «подкаст» с двумя голосами-ведущими. Похоже на озвучку, но диалог
  ведущих между собой, без ученика и без проверки знаний.
- **Microsoft Study and Learn Agent** (Copilot for Education) — карточки, квизы,
  «заполни пропуск» по своим материалам. Сильнее всех в разнообразии заданий, но
  текстовый чат, без озвучки.
- **Microsoft Reading Coach** — ребёнок читает вслух, ИИ слушает и даёт обратную связь
  в реальном времени. Похоже на нашу механику «ученик говорит — ИИ оценивает», но узко
  (только техника чтения).
- **OpenAI ChatGPT Study Mode** — сократовский диалог, спрашивает что уже знает ученик.
  Без голоса, без сценарного «урока по учебнику».
- **Perplexity for Education** — поиск с цитированием + Learn Mode (флеш-карточки и
  квизы из материалов). Исследовательский инструмент, не ведущий-учитель.

## Конструкторы: сам создаёшь урок с помощью ИИ

- **OpenMAIC** (Tsinghua University, MIT-лицензия) — https://github.com/THU-MAIC/OpenMAIC
  — по теме или PDF за ~30 минут и <$2 генерирует полный курс: слайды, тесты,
  симуляции; несколько ИИ-агентов играют роли «учителя» и «одноклассников». Ближе всех
  технологически к архитектуре Klassio (мультиагентный учитель, диалог, генерация из
  документа), но фокус на веб-интерфейс, не на голосовой аватар с распознаванием речи
  ребёнка. 25 900+ звёзд на GitHub.
- **Nolej** — https://www.nolej.io — загружаешь видео/PDF/текст (до 4 источников) → за
  минуты готовый интерактивный модуль: 15+ типов активностей, экспорт в SCORM/H5P.
  Ближе всех к «загрузи → получи курс», но без синтеза голоса.
- **Coursebox AI** — https://www.coursebox.ai — из документа за ~2 минуты строит курс с
  видео, картинками, тестами и AI-тьютором. Единственный, кто автогенерирует ещё и
  видео-компонент плюс полноценную LMS.
- **SchoolAI** — https://schoolai.com — учитель создаёт «Spaces» — сценарии с
  ИИ-тьютором для учеников, сам наблюдает прогресс на дашборде. Даёт ученику живой
  текстовый диалог внутри заданных учителем рамок — близко по идее, но без озвучки.
- **MagicSchool AI / Eduaide.ai / Curipod** — генераторы планов уроков, тестов,
  интерактивных слайдов для учителя. Урок всё равно ведёт человек — не готовый продукт
  для ученика.

## Видео-аватары: генераторы говорящих голов с образовательными кейсами

- **HeyGen** — https://www.heygen.com — отдельный продукт «Interactive Avatar»: живой
  двусторонний видеодиалог в реальном времени (не просто ролик), есть готовый
  Educational Video Maker.
- **D-ID** — https://www.d-id.com — talking-head API + «Visual AI Agents» —
  real-time интерактивные аватары с низкой задержкой, явный edu-лендинг.
- **Colossyan Creator** — https://www.colossyan.com — позиционируется прямо на
  обучение (training-first): аватары с синхронной мимикой на всех тарифах, липсинк
  из коробки, SCORM-экспорт. От $59/мес.
- **Synthesia** — https://www.synthesia.io — крупные edu-кейсы в вузах (IU Германия:
  28 000+ видео для 100 000+ студентов), но фокус на higher ed / corporate, не K-12.
- **Elai.io** — https://elai.io — бюджетный аватар-генератор для L&D, от $29/мес,
  липсинк «не топ, но дёшево».

## Российский/СНГ рынок (прямые конкуренты по географии)

- **Учи.ру** — в 2026 запустила бесплатный ИИ-сервис «Подготовка к уроку»: чат-бот
  генерирует УЧИТЕЛЮ материалы по предмету/классу/теме. Не голосовой репетитор для
  ребёнка.
- **Яндекс.Учебник** — «Репетитор AI» по математике (5–8 класс) на YandexGPT + ИИ-помощник
  для ЕГЭ по информатике. Текстовый/интерактивный формат, без голоса и аватара.
- **ЯКласс** — тренажёры с адаптацией сложности; публичных данных о голосовом ИИ-учителе
  не найдено.
- **Skysmart / Фоксфорд / Умскул** — ставка на живых репетиторов и объём видеоконтента;
  явных голосовых ИИ-уроков в 2025–2026 не анонсировано.
- **GetCourse** — инфраструктура для запуска курсов третьими лицами, точечные ИИ-функции
  (текст, озвучка слайда). Косвенный конкурент.

## Что стоит признать честно

Полного аналога Klassio (готовый видео-аватар + голосовой ответ ребёнка + чтение
конкретного учебника целым уроком со сценарием) в чистом виде не нашли. Ближе всего по
кускам: **eSelf** (аватар+диалог+масштаб на страну), **OpenMAIC** (архитектура
мультиагентного учителя, генерация из документа), **Amira** (голосовой ввод ребёнка
именно для учёбы), **Tavus** (техстек realtime-аватара). На российском рынке ИИ пока
везде «под капотом» (генерация заданий учителю), голосового ИИ-учителя для ребёнка
никто не показал.
