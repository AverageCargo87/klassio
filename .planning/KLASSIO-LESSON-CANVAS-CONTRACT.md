# Контракт канваса урока Klassio (для Claude Design → бэкенд)

Как делать новый урок: рисуешь визуал в Claude Design на базе астрономии
(`public/tutor/anya.html`) как бренд-шаблона, отдаёшь мне готовый HTML — я
подключаю голос/БД/трекинг. Чтобы HTML «воткнулся» без переделок, он должен
соблюдать контракт ниже. Это ровно то, что уже делает `anya.html` — новый урок
повторяет ту же «распайку», меняя только содержимое досок и заданий.

---

## 1. Что HTML ДОЛЖЕН выставить наружу (window)

Голосовой слой (React) общается с канвасом через два глобала во `window` iframe.

### `window.__klassioEngine` — объект-мост, канвас создаёт его сам

React вызывает эти методы (канвас обязан их реализовать):

| Метод | Что делает в канвасе |
|---|---|
| `setStatus('listening'\|'speaking'\|'thinking')` | индикатор состояния Ани |
| `setCaption(text)` | подпись под аватаром |
| `setMuted(bool)` | вид кнопки микрофона |
| `setChildName(name)` | имя ребёнка в чате/подписях |
| `setTeacherName(name)` | имя учителя (аватар + чат) |
| `showStartButton()` / `hideStartButton()` | центральная кнопка «Начать урок» |
| `setStartButtonText(text, disabled)` | текст/состояние кнопки |
| `startTimer()` | запустить таймер урока |
| `setVoiceMenu(voices, selectedKey)` | меню выбора голоса на аватаре |
| `showBoard(variant, animate?)` | **показать доску по имени** (см. §2) |
| `showTask(step, animate?)` | показать тренажёр (объект задачи из §3) |
| `hideTool(animate?)` | убрать доску/тренажёр, пустой холст |
| `pushBubble('tutor'\|'child', text)` | добавить реплику в чат |

Канвас ВЫСТАВЛЯЕТ эти колбэки = null, React их назначит (канвас вызывает, когда происходит событие):

| Колбэк | Канвас вызывает, когда |
|---|---|
| `onStart()` | нажата «Начать урок» |
| `onMute(isMuted)` | нажата кнопка микрофона |
| `onSolve(step)` | ребёнок решил задачу ПРАВИЛЬНО (`step` = текущая задача) |
| `onWrong()` | ребёнок выбрал неверный вариант |
| `onVoiceSelect(key)` | выбран голос в меню |
| `onPlanetClick(name)` | ребёнок кликнул интерактивный объект на доске (опционально) |

### `window.__KLASSIO_REAL_LESSON` — массив задач урока

Канвас публикует сюда задачи (см. формат §3). React по `show_trainer(taskId)`
берёт из него `tasks.filter(s => s.type === 'task')[n-1]` и зовёт `showTask(step)`.

---

## 2. Доски (boards)

Каждый урок = упорядоченный набор досок. Имена досок СВОБОДНЫЕ (для астрономии:
`cover, etymology, bodies, solar, sunEarth, facts`), но:

- **первая доска — всегда `cover`** (обложка-заголовок, без 60-сек пола);
- остальные — теоретические (на каждой ребёнок задерживается ≥60 сек);
- зарезервировано имя **`reward`** — экран «урок пройден» (рисуй в фирменном стиле).

`showBoard(variant)` должен уметь нарисовать любую доску по имени. `next_slide`
листает их по порядку — порядок я задаю на стороне React (одна строка на урок),
**пришли мне список имён досок в нужном порядке** вместе с HTML.

Доски могут быть интерактивными (как карта Солнечной системы): по клику зови
`onPlanetClick(name)` — Аня прокомментирует. Это опционально.

## 3. Формат задачи (что лежит в `__KLASSIO_REAL_LESSON`)

```js
{
  type: 'task',
  id: 'q1',                 // уникальный id
  board: 'etymology',       // на какой доске показывать (имя из §2)
  variant: 'choice',        // 'choice' = выбор варианта | 'blank' = ввод в поле
  q: 'Что такое акция?',    // текст вопроса
  answer: 'доля компании',  // правильный ответ (для blank)
  explain: 'Верно! Акция…',  // короткое пояснение после ответа
  options: [                // только для variant:'choice'
    { t: 'доля компании', correct: true },
    { t: 'долговая бумага' },
    { t: 'вклад в банке' },
  ],
  hints: ['подсказка 1', 'подсказка 2'],   // опционально
  skill: 'what-is-a-stock',  // тег навыка (для прогресса в ЛК) — желательно
}
```

Когда ребёнок ответил верно → канвас зовёт `onSolve(step)`; неверно → `onWrong()`.
**`skill`-тег важен** — по нему строится прогресс по темам в личном кабинете.

## 4. Что я доделываю на своей стороне (тебе не трогать)

- порядок досок и число задач на урок (одна строка конфига на урок);
- голос (Sber/11labs), STT/TTS, очередь аудио;
- системный промпт Ани под тему урока (содержание + сценарий);
- запись сессии: транскрипт, AI-резюме, домашка, прогресс — всё в БД/ЛК;
- маршрут `/tutor[-ru]/<subject>/<slug>` и резолв урока.

---

## 5. Чек-лист сдачи урока из Claude Design

1. HTML открывается standalone, создаёт `window.__klassioEngine` со всеми методами §1.
2. `window.__KLASSIO_REAL_LESSON` заполнен задачами по формату §3 (с `skill`-тегами).
3. Первая доска — `cover`, есть доска `reward`; прислан **список имён досок по порядку**.
4. Все доски рисуются через `showBoard(name)`; тренажёр — через `showTask(step)`.
5. `onSolve/onWrong` вызываются на ответах; визуал — в фирменном стиле Klassio.
6. Прислан короткий текст: тема урока, аудитория, сценарий (для промпта Ани).

> Если соблюдён §1–3, подключение к голосу и БД у меня занимает часы, а не дни:
> весь бэкенд (сессии, трекинг, ЛК, голос) — урок-агностичный.
