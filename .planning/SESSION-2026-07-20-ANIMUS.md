## 🔴 ГЛАВНОЕ: концепция «Анимус»

Ребёнок сидит в пустом **белом пространстве для симуляций** (референс — Анимус из Assassin's Creed), может только вертеть головой. Три объекта — **доска, робот-ассистент, экран учителя** — всегда есть и трактуются как реальное оборудование. Потом «запускается симуляция», и вокруг **отрисовывается мир под тему урока**. Мир умеет растворяться обратно в белое.

**Почему сильно:** убивает проблему поиска моделей классов (белая пустота бесплатна и всегда выглядит намеренно); превращает бюджетное ограничение в стиль; одна база + сменные миры = 50 уроков без 50 сборок; момент загрузки = вау-крючок каждый урок; неподвижность ученика становится ЛЕГЕНДОЙ, а не ограничением.

**Ключевой инсайт (мой, Кратов не возражал):** переключение «белое ↔ мир» — не украшение, а **рычаг управления вниманием**. Отвлёкся → «уберём лишнее» → мир втягивается в доску, остаётся задача. Решил → мир возвращается наградой. Ни у кого на рынке этого нет.

### Решения Кратова (ЗАФИКСИРОВАНЫ, не переспрашивать)
1. **Белое** = сетка/каркас Анимуса + тёплый белый градиент. Сразу читается «мы в симуляторе», но тепло: аудитория дети/младшие подростки ~9–13 (не малыши → не мультяшно; не взрослые → не стерильно).
2. **Материализация** = мир **плавно собирается по кусочкам**: каркас→заливка ПЛЮС прилетающие частицы.
3. **Класс = 3D-МОДЕЛЬ** (не панорама). «Попробуем генерации + готовые бесплатные ассеты, но если что я сам в блендер умею».
4. **Учитель = РОБОТ, не человек.** Дословно: «так сможем объяснить почему он молчит». Это снимает всю проблему липсинка. 3D-модель человека НЕ брать.
5. Робота из Анимуса **убрал** («стрёмный») — там сейчас только доска + экран учителя.

### `/animus` — устройство

- **Убрать мир:** 0.85 с, easeOutQuint, втягивание в доску, частицы выключены (НЕ реверс сборки — читался бы как глитч).
- **5 тем:** 🪐 космос · 🌕 Луна · 🏛 колоннада · 🥐 пекарня · 📦 отсек (площадь).
- **Живой воздух:** `THREE.Points` 900 шт, анимация в вершинном шейдере, 1 draw call. Мука/пыль/искры по темам.
- ⚙-панель: **скраб прогресса** (покадрово смотреть фронт), камера, туман, сетка, длительность.
- Дебаг: `window.__a()`, `__step(n,dt)`, `__look(yaw,pitch)`, `__shot()` (гистограмма кадра).

## 🔴 ГРАБЛИ, НА КОТОРЫЕ Я НАСТУПИЛ (не повторять)

1. **`new THREE.Color(hex).convertSRGBToLinear()` — ДВОЙНАЯ конверсия.** С r152 ColorManagement включён по умолчанию, `new THREE.Color(hex)` УЖЕ переводит sRGB→linear. Замерено: `#FDFAF5` рендерился как `#FAF4E9` (темнее, желтее). **Исправлено в animus.html, но НЕ проверено в остальных скетчах — поискать.** Проверка: `new THREE.Color(hex).getHexString()` должен вернуть исходный hex.
2. **`#define` в GLSL обязан быть на СВОЕЙ строке** — иначе «invalid character», шейдер не собирается, небо чёрное.
3. **Box3 ВРЁТ на риггованных моделях** (bind-pose/скелет раздувают габарит: у робота 3.34 м «ширины» при 1.45 м высоты → scale выходил 0.01, робот микроскопический). Мерить по **мировым позициям КОСТЕЙ** (`isBone` → matrixWorld).
4. **`onBeforeCompile` компилится лениво** → инициализировать uniform текущим значением, а не нулём.
5. **Консоль встроенной панели НЕ чистится при навигации** — старые ошибки шейдера висят после фикса. Сверять `curl`-ом отдаваемый файл.
6. **Скриншот WebGL во встроенной панели виснет** — это норма, верифицировать через `__shot()`/DOM, не скриншотом.

## ЗАФИКСИРОВАННЫЕ ТЕХ-РЕШЕНИЯ (ресёрч, не переоткрывать)

### Архитектура окружения
**Параллакс возникает ТОЛЬКО при перемещении камеры.** Камера, которая лишь поворачивается, видит нулевой параллакс → для сидящего ученика объект на панораме и он же геометрией **математически неразличимы**. Слои: пол = всегда геометрия; 0–8 м = настоящее 3D (оборудование + 3–6 геройских предметов); 8 м+ = панорама. **Новая тема = 1 панорама + 3–6 предметов**, а не «3D-сцена».

### 🔴 Узкое место — ПАМЯТЬ ПОД ТЕКСТУРЫ, не полигоны
Формула three.js: `ш × в × 4 × 1.33`. Одна карта 2048² = **22.3 МБ**; 20 ассетов × (альбедо+нормаль) = **~892 МБ** → смерть на встроенной видеокарте. При этом 1.2 млн треугольников — норма. Наша сцена: **69.8 МБ, с запасом**. Правила: героические текстуры ≤1024², панорама ≤4k, KTX2/Basis даёт ×4-8.

### Ассеты (всё CC0, всё GLTF, всё доступно из РФ — проверено замером)
**KayKit** (основа, единый атлас = и стиль, и draw calls) + **Tiny Treats** (пекарня, специально подогнан под KayKit) + **Kenney** (200 еды/140 мебели) + **Quaternius Gen 2** (⚠️ Gen 1 «Ultimate ___» НЕ отдаёт glTF) + **Loafbrr** (Луна). Панорамы — **Poly Haven** (980 шт, все ровно 2:1, скачиваются на 275 КБ/с).
**AI-генерация 3D НЕ нужна:** готовый CC0-хлеб = 412 треугольников против ~412 000 у Meshy; практики единогласно «static-prop-ready, НЕ animation-ready», 1–2 ч чистки на ассет.
**Лицензионное правило:** отвергать всё, где есть «post on a web server» / «в формате, допускающем скачивание» — скайбокс это буквально файл для браузера. Выбивает Fab/Epic, HDRMAPS, hdri-skies, locationtextures. Также ⚠️ **Khronos glTF-Sample-Assets — НЕ библиотека**: `DamagedHelmet` отравлен CC BY-NC.
**Проверено моим замером вопреки отчётам:** itch.io, kaylousberg, tinytreats, mixamo, huggingface — **все 200 с машины Кратова**. Утверждения «itch.io заблокирован РКН» не подтверждаются. **Всегда проверять замером, а не источниками.**

### Анимация скайбокса
**360-видео не шипить:** 50 уроков = 1.5 ГБ против 60 МБ статикой; кадр 4096×2048 = 33.6 МБ в текстуру 60 раз/сек; известный обрыв three.js #26183 роняет 60→7 fps. **Вместо:** ① частицы вблизи (собрано) ② две оболочки (статичный перед + вращающееся небо) ③ шейдерный варп неба по маске. **Параллакс-оболочки физически не работают** (чистая гомография).

### Математика в Анимусе — ЗАКОН (4 линзы независимо сошлись)
1. **КОМНАТА ЕСТЬ ВЕЛИЧИНА**, а не сцена вокруг задачи. Тема не измерительная → 3D-мира не полагается.
2. **ОТВЕТ РАЗЫГРЫВАЕТСЯ, А НЕ ВВОДИТСЯ.** Поле ввода = смерть мира за одну итерацию.
3. **МИР ФАЛЬСИФИЦИРУЕТ:** ошибка ломает мир видимо и обратимо (кабель не сошёлся), а не краснеет.
4. Арка: мир строится → понял телом → мир растворяется → в белом отрабатываем процедуру → мир возвращается наградой.
**Первым строить:** «Отсек-трансформер» (площадь/периметр). **Отброшено:** столбик как мир (это нотация, не место), рынок/проценты, пиццерия для дробей.
