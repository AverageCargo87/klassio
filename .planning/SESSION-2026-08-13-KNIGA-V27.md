## 🔑 Грабли этого круга (дорого купленные)

- **`\w` в JS не видит кириллицу.** Правило про «легендарного царя Миноса» молча не срабатывало.
  Окончания русских слов писать `[а-яё]+`, `\b` вокруг русских слов не использовать.
- **`rr.words` — ЧИСЛО, а не массив.** Проверка `.length` на нём давала `undefined`, и честно
  прочитанный текст засчитывался как «промолчал». Шаг проскакивал целиком.
- **`zakrep.json` — генерируемый файл, но правленный руками.** Слепая перегенерация
  `make-zakrep-data.mjs` стёрла чужие правки картинок четырёх карточек (поймано приёмкой).
  Правильно: точечно дописать поле в существующий файл, а таблицу правок держать в генераторе.
- **Две подписки на `ctrlWait()` в одном шаге = гонка.** У ожидания нажатий есть очередь
  (`ctrlQ`), и второй `ctrlWait()` может резолвиться мгновенно отложенным значением.
- **Приёмка адресовала такты НОМЕРОМ.** Любая вставка в сценарий (а их в этом круге три)
  сдвигает номера, и проверки начинают смотреть не туда. Теперь есть `beatByText`.
- **Гонка промисов на шве приёмки.** `Promise.race([шов, кнопка])` выигрывался кнопкой, а шов
  после этого съедался вхолостую. Заменено явной проверкой в цикле.

## Как теперь принимать видеоразборы

Владимир присылает запись экрана с голосом. Расшифровка делается локально на RTX 3060,
без облаков, за минуту:

```
.tmp/asr-venv/Scripts/python.exe scripts/transcribe.py .tmp/video-in/<файл>.mp4
```

Рядом ляжет `<файл>.transcript.md` — абзацы с таймкодами. Запасной путь, если GPU занят или
модель не скачана: `node scripts/transcribe-yandex.mjs <файл>.wav` (режет по паузам, шлёт в
SpeechKit; без пунктуации).

⚠️ Веса whisper качались через зеркало: CDN HuggingFace из РФ рвёт соединение. И CTranslate2
ищет `cublas64_12.dll` в системном PATH — в `scripts/transcribe.py` для этого подставляется
папка `torch/lib` соседнего окружения (комментарий в файле).

Разбор записи на задачи — `.planning/KNIGA-REVIEW-2026-08-13.md`: одна задача = одна цитата
с таймкодом, чтобы можно было перепроверить, а не поверить на слово.
