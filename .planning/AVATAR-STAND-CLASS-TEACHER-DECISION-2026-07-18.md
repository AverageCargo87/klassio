# Иммерсив-класс v2 — решения по 4 задачам руководителя (аватары, класс, учитель, поведение)

*Решенческая записка, пересылаемая руководителю. Собрано многоагентным ресёрчем 2026-07-18 (26 агентов, адверсариал-проверка цен + РФ-доступности по каждому провайдеру). Диапазоны — намеренно.*

Руководитель одобрил вектор (иммерсивный класс с ходящим 3D-учителем) и попросил: **(1)** красивый класс под одного ученика, **(2)** нормальную 3D-модель учителя, который ходит и что-то делает, **(3)** придумать, что он делает, **(4)** стенд-сравнение 5–6 альтернатив Anam (реалистичнее, дешевле; претензии к Anam — дорого + качество не идеал).

---

## Два жёстких гейта, которые всё решают (важнее цены)

1. **РФ-доступность без VPN.** Anam из РФ достаёт (`connect-eu.anam.ai` + Cloudflare TURN). Simli — **нет** (единственный GCP-хост `api.simli.ai`, WS 1006). Это убило Simli несмотря на то, что он в 10× дешевле. → Провайдер обязан коннектиться из РФ, иначе он не кандидат.
2. **BYO-audio (свой русский звук).** Мы отдаём готовый Yandex-TTS (alena/julia) — аватар должен принимать наш звук (passthrough), а НЕ навязывать свой TTS. Иначе русское качество падает до чужого голоса.

**Эти два гейта сразу выбивают двоих:** **Akool** и **A2E** — их realtime-аватар принимает только ТЕКСТ и озвучивает своим TTS (нет BYO-audio). Realism-преимущество для русского обнуляется. Отброшены.

### Что реально трогать на стенде (по приоритету)
1. **bitHuman** — потенциально дешевле всех (×3–8 под Anam), простой не биллит, self-host под 152-ФЗ, своя Аня за $5, **free 99 кредитов без карты**. Проверить реализм глазами.

3. **HeyGen** — **free-tier без карты → можно проверить РФ-коннект и русский липсинк прямо сейчас**, без решения проблемы оплаты.
4. **D-ID** — не биллит простой, своя Аня из фото; но РФ-коннект под вопросом — тест первым делом.
5. **Tavus** — только если хотим показать руководителю ПОТОЛОК реализма; дорого + оплата из РФ проблемная.

**Оплата из РФ — главный НЕ-технический блокер** для Tavus/HeyGen/BeyondPresence (карты РФ не проходят с 2022 → Wise / казахстанский Kaspi / реселлер). Поэтому начинаем с тех, у кого **free-tier без карты**: HeyGen, bitHuman, D-ID-trial.

### Self-host — трек «на масштаб + 152-ФЗ» (0 иностранных хопов)
- **MuseTalk 1.5 + LiveTalking** (MIT, коммерция OK) — realtime 45–72 fps на RTX-4090-класс, WebRTC + barge-in, BYO-audio родной, **~$0.4–1.0/урок** на РФ-GPU. Первый прототип.
- **Ditto-talkinghead** (Apache-2.0) — качество-потолок опенсорса (RTF<1, первый кадр <400мс), нужен A100/L40S, ~$1.8/урок. Апгрейд.
- Только офлайн (для маркетинг-клипов, не живой урок): LatentSync (лучший липсинк), HeyGem. **НЕ брать Wav2Lip** (лицензия запрещает коммерцию).
- Оговорка: talking-head realtime = **1 GPU на 1 одновременного ученика** → на масштабе стоимость = пиковая одновременность, не сумма уроков.

## Задача 1 — Класс под одного ученика

**Рекомендация: панорама-first (гибрид), опционально + 3D-модель.**

Наш текущий `room.glb` — генерик 101k tri со множеством парт. Замена:
- **Панорама-гибрид (рекомендую):** equirectangular-360 уютного кабинета фоном (CC0 Poly Haven «Reading Room» / FLUX-LoRA) + поверх ДВЕ живые интерактивные плоскости (доска + стол). Ученик сидит, камеру ведёт Аня — панорама даёт ровно ту «несвободу» (осмотр без хождения), которую требует наш закон режимов. **Дешевле** (≈0 tri vs 101k), **красивее** (фотореал), **РФ-safe** (CC0, self-host JPG на VPS), и синергия с идеей морфинга сцен (сменил картинку → сменил настроение).
- **Если руководитель хочет именно 3D-МОДЕЛЬ комнаты:** лучший выбор — **Quaternius Ultimate House Interior Pack** (CC0, GLB, набор — собираем ровно 1 стол+стул+полка+ковёр, парты сокращать не надо). Готовые «премиум»-комнаты: ARTEL_3D «Cozy Interior Scene» / Hamoza «Study Room» (CC-BY, децимировать до ~120–150k). Все найденные — CC-BY/CC0 (NonCommercial нет).

## Задача 2 — Нормальная 3D-модель учителя, который ходит/делает

**Рекомендация: Ready Player Me сейчас → Character Creator 4 когда нужен «премиум».**

- **Сейчас (быстро, $0, kid-safe):** сгенерить бесшовную полноростовую **Аню в RPM** (не генерик «girlfriend/Nanami», что сейчас захардкожен), экспорт с `?morphTargets=ARKit,Oculus%20Visemes` (52+15 морфов), скачать 1 GLB и **раздавать со своего VPS/jsdelivr** (сам readyplayer.me из РФ заблокен, но jsdelivr-GLB грузится — уже проверено). Бесплатная регистрация Klassio как RPM-разработчика = коммерция за $0.
- **Апгрейд (когда нужен «покрасивее»):** **Character Creator 4** (~$299 разово, IP твой) — дайл от стилизации до почти-фотореала, 52 ARKit + AccuLips, богатейшая библиотека учительских жестов (ActorCore). Нужен день 3D-художника.
- Отклонены: Avaturn (взрослый-фотореал = uncanny на детском продукте + ~$800/мес за один аватар), AvatarSDK (энтерпрайз), VRoid (аниме + всего 5 висем).

### Как оживить (стратегия анимации — 3 слоя на одном AnimationMixer)
1. **База (стейт-машина):** клипы idle / talk-idle / walk / point / write / celebrate / think, переключение `crossFadeTo(0.3s)`. Клипы — **библиотека `readyplayerme/animation-library`** (уже ретаргечены на RPM-риг → ноль боли с Mixamo). Сырой Mixamo на RPM тащить НЕ надо (перевёрнутые ступни/руки).
2. **Аддитив «живость» (всегда вкл):** дыхание `makeClipAdditive` поверх любой базы — микро-качание корпуса ~0.2 Гц, перенос веса → она никогда не «манекен».
3. **Процедурное (код):** моргание + **саккадный gaze** (голова/глаза смотрят на ученика/доску через lookAt-кватернион) — этот один трюк продаёт «она смотрит на меня»; + **висемы из звука** — заменить текущий хак `jawOpen`-по-амплитуде на браузерный классификатор (wawa-lipsync / TalkingHead HeadAudio, MIT) → 15 Oculus морфов.
4. **Оркестровка:** DeepSeek уже знает начало/конец реплики → пусть отдаёт тег-жест `{gesture:'point'}` рядом с ответом → фронт маппит на клип → **жесты осмысленные** (показывает когда ссылается на доску, палец вверх на верный ответ), а не случайный idle-шум.

## Задача 3 — ЧТО учитель делает (репертуар поведения)

Каждое движение привязано к учебной цели (никакого случайного брожения). Порядок сборки = приоритет.

### P0 — база «живости» + чинит talk-over (строить первым)
- **faceChild** — поворот головы+корпуса к ученику ПЕРЕД тем как задать вопрос/личное. Самый дешёвый сигнал жизни.
- **waitForChild (ask-then-WAIT)** — после вопроса: шаг назад, поворот к ученику, открытая поза ожидания, **TTS МОЛЧИТ** — настоящая тишина на подумать; подсказка только по таймауту, никогда не ответ. Прямо чинит регресс talk-over/латентности из прошлых демо.
- **pointAt + подсветка доски** — рука на конкретную область слайда (слово «астрон», кратер, планета) + синхронный glow → совместное внимание.
- **Заслуженная конкретная похвала** — celebrate (хлопок/палец вверх/подскок) + конфетти + похвала за то, что ребёнок РЕАЛЬНО сделал («ты сам разгадал слово!»), не generic «молодец».
- **Обратный отсчёт синхронно с жестом** — «три… два… один!» + взмах руки, слайд/сцена приземляется РОВНО на «один».

### P1 — осмысленное движение
- **Проксемика:** `walkTo('besideChild')` на моменты чуда (смотрим вместе), `walkTo('board')` когда ход ученика (отдать пространство).
- **«Подойди и назови ЕГО выбор»** — после ответа подойти, показать на выбранный им вариант, среагировать на него по имени («ты поставил 8…») ДО оценки верно/неверно.
- **Переобъяснить другой картинкой, не громче** — на ошибку: тёплая поза размышления (без «неправильно»), палец на подсказку, другая репрезентация/аналогия, один управляемый повтор.
- **Реакция-удивление** (awe): полшага назад, взгляд ВВЕРХ на картинку, руки вверх, тише/медленнее через SSML («вооот это да…») — контраст громко→тихо перезапускает внимание.
- **Совместный взгляд вверх / «сделай со мной»** — каждые ~2–3 мин ломать пассивность, хэндофф в квиз.
- **Телесный масштаб** — своим телом как линейкой: рядом с «Землёй» → идёт через комнату к гигантскому «Солнцу», руки широко, ужимаясь в точку («…в 109 раз шире!»).

### P2 — слой пропсов/игры (в рамках закона огранич. движения ученика)
- **Манипулятивы:** взять 3D-глобус/телескоп на уровень глаз, повернуть один раз называя; телескоп → доска в увеличение. Манипуляция ребёнка = on-rails клик/драг.
- **Опуститься на уровень глаз ребёнка** на его ход.
- **Коллекционный прогресс:** звёздная карта на стене / полка бейджей — заработал → зажёгся launch к следующей локации.
- **Таймер-микроквест** (опц.): «быстрее, пока не пролетела комета — кликни ближайшую к Солнцу планету!».

### Как встроить (контракт — только ДОБАВЛЕНИЯ, ничего не ломаем)
- Текущий `STAGES`/BOARDS в `astronom-3d.html` расширить **опциональным `choreo`**-массивом директив: `[{do:'walkTo',arg:'board'}, {do:'point',region:'astron'}, {do:'wait',hint:'…'}, {do:'reveal',countdown:true}]`. Есть `choreo` → движок читает; нет → сегодняшнее поведение. Апгрейд по одной доске.
- Заменить орб `#anya` на риггованный аватар в той же сцене; подпись остаётся субтитром. **Graceful degrade:** нет GLB/клипа/якоря → откат на caption+say, урок не встаёт.
- Соблюсти закон режимов: `walkTo`/якоря двигают АВАТАР внутри камеры, ведомой учителем — не отдают камеру ребёнку.
- **Гард латентности:** `choreo` секвенится по границам say/TTS; `waitForChild` глушит TTS на подумать; жесты — на границах реплики, не поверх речи. Не воскрешать talk-over.
- Новые примитивы: `lookAt/faceChild/faceCamera`, `lookUp`, `walkTo(anchor)`+`walkPath`, `pointAt(x,y)+highlightOnBoard`, `waitForChild`, `revealSlide(countdown)`, SSML-хук в `say()`, `reteach(concept)`, gaze-follow-cursor, пропсы+HUD (P2).
