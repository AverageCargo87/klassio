# Бриф дизайна ЛК Klassio (для Claude Design → бэкенд)

Бэкенд кабинета готов (ветка edu-platform-cabinet). Ты рисуешь экраны в фирменном
стиле, я подключаю к реальным данным. Ниже — экраны и ТОЧНЫЕ поля данных на каждом
(названия = как отдаёт сервер; рисуй под них, ничего не выдумывай сверх списка).

Аудитория ЛК — РОДИТЕЛЬ (смотрит, как учится ребёнок). Тон взрослее, чем урок, но
тот же бренд: тёплый, скруглённый, спокойный.

---

> **АРХИТЕКТУРА: по предметам, а не общий хаб.** Общие суммы по всем предметам
> (точность математики + окружающего мира) бессмысленны. Поэтому: главная =
> запуск по предметам с уведомлениями, цифры и подробности — ВНУТРИ предмета.
> Это кабинет РОДИТЕЛЯ про ребёнка — никаких «Привет, {имя}» (это не к ребёнку).

## Экран 1 — Главная кабинета · `/cabinet`
Шапка нейтральная, к родителю: «Учёба {childName} · {класс}» (НЕ «Привет, Миша»).
Карточки **предметов** (растут: Математика, Окружающий мир, **Финансовая грамотность** — новый):
- иконка, название, класс, 1 строка «следующий урок: …»
- **чипы-уведомления с подписью ЧТО это** (если есть, иначе карточка спокойная):
  · «N домашки» (homework по этому subjectId, `status==='assigned'`)
  · «N замечаний» (moderation по сессиям этого предмета, непрочитанные)
  · «урок идёт» (если есть in_progress)
- клик → страница предмета.
БЕЗ общих сумм точности/заданий на главной.

## Экран 2 — Страница предмета · `/cabinet/[subject]`
Всё по ОДНОМУ предмету (данные фильтруются по `subjectId`). Секции:
- **Шапка + цифры по предмету:** уроков пройдено, точность % (по сессиям этого предмета).
- **Незаконченный урок** (`status==='in_progress'`) — «Продолжить».
- **Домашняя работа** (этого предмета): `title`, пункты `items[].q`, кнопка «Отметить выполненным».
- **Уроки — программа:** прошедшие (`lessonTitle`, дата, точность %, X/Y, длительность; клик → запись урока) И будущие/предстоящие (из curriculum: `available` / `coming-soon`).
- **Поведение/замечания** (по предмету): не просто «отвлёкся», а ПОДРОБНО — что произошло, с привязкой к моменту урока (ссылка на запись урока, где это было; для грубости — тоже). Кнопка «Ясно».
- **Темы и навыки** (этого предмета): `skillTag` + прогресс-бар `masteryLevel`, слабые сверху.

## Экран 3 — Запись урока · `/cabinet/lessons/[id]`
Шапка: `lessonTitle` + дата. Две секции:
- **«Замечания учителя»** — текст `summary` (AI-резюме урока, выделенная карточка)
- **«Запись урока»** — лента реплик `transcript[]`: `role` ('agent'=Учитель / 'child'=Ребёнок) + `text`. Реплики учителя и ребёнка визуально разнести (как чат). Сюда же ведут ссылки из «Поведения» (показать момент).

## Доступные данные (реальные поля бэкенда — рисуй под них)
```
childName: string
ChildReport:
  totals: { lessonsCompleted, tasksTotal, tasksCorrect }
  sessions[]: { id, subjectId, lessonSlug, lessonTitle, status, attemptNumber,
                startedAt, endedAt, durationSec, tasksTotal, tasksCorrect,
                accuracy(0..1|null), summary(string|null), hasTranscript(bool) }
  skills[]: { skillTag, masteryLevel(0..1), attemptsTotal, correctTotal, lastPracticedAt }
  moderation[]: { id, type, createdAt, acknowledgedAt(null=не прочитано) }
  unacknowledgedModeration: number
homework[]: { id, lessonSlug, title, items[]{q,answer?,options?,skill?}, status, createdAt, completedAt }
transcript[]: { role('agent'|'child'), text, seq }
```

## Чек-лист сдачи ЛК из Claude Design
1. Три экрана выше, в фирменном стиле дизайн-системы Klassio.
2. Используются только перечисленные поля (под них и верстай: пустые состояния — «занятий пока не было», «домашки нет» — тоже нарисуй).
3. Действия-кнопки помечены (родитель жмёт): «Продолжить» урок, «Отметить выполненным» домашку, «Ясно» замечание, «Открыть запись» урока — я повешу обработчики.
4. Десктоп + мобильный (родитель часто с телефона).
5. Отдай HTML/React — подключу к реальным данным за часы (бэкенд готов).
