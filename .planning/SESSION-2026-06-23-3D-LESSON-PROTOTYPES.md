## Решения, зафиксированные (locked)
1. **Закон управления:** Аня — режиссёр внимания и пространства; ученик СИДИТ, look-around ±~30°, НИКАКОГО свободного перемещения по умолчанию. Свободу перемещения отдаём как **заработанную награду / паузу при усталости** (ограниченная зона + таймер + закрывает учитель).
2. **5 сырых режимов Кратова пересобраны** → 3 оболочки (A Кино-сайт / B Карта-путешествие / C Класс-мир) + 2 слоя-вау (L1 3D-объекты / L2 360-фон). B вычеркнут (растворился в C). Итог = Сайт vs Иммерсивный класс.
3. **C переопределён Кратовым:** сидишь за партой → телепорт на поверхность (Луна/Марс), обстановка морфится вокруг, доска адаптивная (на стене → парящая Apple-Vision).
4. **Ценность 3D УСЛОВНА** (Кратов сам засомневался «только вау»): высокая для пространственных тем (окр.мир/астрономия/география/тело/история) + маркетинг; ≈0 для абстрактного (математика/русский). Стратегия: 3D для пространственных тем, 2D-сайт — ежедневная лошадка.
5. **Учитель переключает слайды И локации** через client tools — расширить контракт: `showLocation('class'|'moon'|'mars')`/`teleport()` к существующим `showBoard`/`showTask`.
6. **Доска — докинг под управлением учителя:** «фокус» (впереди, читаемо) во время задачи ↔ «в стороне» во время исследования. Дефолт читаемо-впереди.
7. **Скайбокс = equirectangular 2:1** (плоскую GigaChat-картинку нельзя — тянется). Супер-360: реальные NASA-панорамы / FLUX-LoRA / Gaussian splatting. 3D-бюджет → в объекты (L1), не в сцены (ученик сидит — дорогие walkable-сцены не нужны).

## Тех-уроки (reusable, НЕ наступать снова)
- **`Object.assign(light,{position:new THREE.Vector3()})` ПАДАЕТ** — Object3D.position read-only, strict-mode модуля → TypeError при загрузке, обрывает скрипт ДО навески обработчиков (кнопка «мёртвая», превью НЕ показал ошибку). Всегда `obj.position.set(...)`.
- DOM рисуется поверх WebGL → живая доска всегда плоский iframe/overlay; 3D = окружение, не сам канвас.
- three.js TextureLoader НЕ читает TIFF; NASA hi-res = EXR/TIF → конверт локально через OpenCV (`OPENCV_IO_ENABLE_OPENEXR=1`, ACES-tonemap для EXR).
- Планетный арт урока = плоские диски (альфа ~0.2-0.4 coverage) → в 3D рисовать как Sprite-билборды, не текстуры сфер.
- FPV-камера: EYE fixed, `camera.rotation.order='YXZ'`, писать только yaw/pitch с клампом ПЕРЕД демпфом, `touchAction:none`, мягкий авто-возврат к доске.
