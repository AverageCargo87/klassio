### 6. 🔴 СВОП hi-res в Claude Design артефакт (главное этой сессии)
Кратов сделал в Claude Design мокап `Downloads/Урок дробей.html` (10 МБ). **Устройство:** картинки в
служебном JSON-хранилище по UUID (`{uuid:{mime,compressed,data(base64)}}`), `<img>` подставляются
рантаймом. 14 картинок: 10 поз (1000×1500) + 4 фона-ячейки (686×464…714×531).
- Кратов заапскейлил позы + перегенерил фоны (hi-res файлы в Downloads с UUID-именами, НЕ совпадают
  с ключами хранилища).
- Пайплайн: `pipeline/artifact_probe.py` (разбор хранилища) → `pipeline/swap_assets.py` (**матч по
  СОДЕРЖИМОМУ**: силуэт для поз, композиция для фонов — сверка глазами через `anya/_swap_verify.png`) →
  запись в **новый** `Downloads/Урок дробей hi-res.html` (оригинал цел).
- 🔴 **ГРАБЛИ: апскейлер убил альфу** (RGB, фон белый 245–254) → позы лезли «коробкой». Починил
  `pipeline/fix_transparency.py` (вырез белого border-connected) + `pipeline/patch_alpha.py` (вживил
  прозрачные обратно). Проверено: canvas-альфа углов = 0.
- **Итог:** заменено 5 поз (think/surprise/point/wave/explain) + 3 фона на hi-res+прозрачные. Артефакт
  рендерится, консоль чистая.

## РАННБУК / СКРИПТЫ (сохранены в `.tmp/sketches/tutor/pipeline/`)
- `slice_anya.py` — лист поз → нормализованные прозрачные спрайты (правь SRC/OUT в начале).
- `slice_worlds.py` — листы 2×2 миров → ячейки.
- `artifact_probe.py` — разбор хранилища Claude Design артефакта (пути в начале файла).
- `swap_assets.py` — матч по содержимому + своп (флаг `--write`; без него dry-run + verify-лист).
- `fix_transparency.py` — вырез белого фона → прозрачность (список CHAR-файлов правь).
- `patch_alpha.py` — вживить прозрачные спрайты в артефакт (MAP: store-uuid → файл).
- Запуск: `python <script>.py` (нужны Pillow+numpy+scipy — стоят).

## КЛЮЧЕВЫЕ ГРАБЛИ
- **Апскейл убивает альфу** → всегда включать вывод PNG с прозрачностью; иначе фон белый → «коробка».
- **Консистентность персонажа** — только одной генерацией (лист), не по одной позе.
- **UUID новых файлов ≠ ключи хранилища** → матчить по содержимому (силуэт/композиция), сверять глазами.
- **Скриншот Browser pane виснет** → верификация через `javascript_tool` (DOM/canvas), не screenshot.
- **Пасты-картинки** Кратова — не в чате, а сохраняются им в `Downloads` (искать там).
