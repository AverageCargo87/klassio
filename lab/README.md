# `lab/` — зеркало исходников витрины под git

⚠️ **Здесь не правят.** Рабочая копия урока живёт в `.tmp/sketches/tutor/`, а сюда файлы
попадают сами при выкладке (`node scripts/lab-deploy.mjs`). Правка прямо в `lab/` на стенд
не попадёт и потеряется на следующей выкладке.

## Зачем эта папка

`.tmp/` лежит в `.gitignore` — вместе с уроком там 1.2 ГБ 3D-хлама от закрытых веток,
рендеры страниц учебника под копирайтом и модели учителя. Поэтому у самого урока **не было
истории правок вообще**: только журнал версий. Зеркало берёт из рабочей копии один текст —
страницы сборок и данные, 1.3 МБ — и кладёт под git. Тяжёлое и копирайтное на сервер
по-прежнему едет пакетом, мимо репозитория.

## Что внутри

| | |
|---|---|
| `lab.html` | витрина: три карточки, «что изменилось», приём замечаний |
| `kniga.html` + `book/{panel,test,drill,zakrep}.json` | **ЧАРЛИ** — текущая сборка |
| `kniga-v23.html` + `book/v23/` | **БРАВО** — заморожена |
| `kniga-v1.html` + `book/v1/` | **АЛЬФА** — заморожена |
| `book/{blocks,figures,marks,marks-src,pages}.json`, `book/map-greece.svg` | **ОБЩЕЕ** — читают все три сборки |

Общее потому и вынесено в отдельную строку: правка в ЧАРЛИ через эти файлы меняет и то, что
руководитель считает замороженным. Выкладка про это предупреждает отдельно.

## Как откатиться

```bash
node scripts/lab-rollback.mjs                      # какие релизы есть
node scripts/lab-rollback.mjs --back               # вернуть на боевом предыдущий
node scripts/lab-rollback.mjs --to 0003 --local    # и вернуть исходники на рабочей машине
```

Метка каждой выкладки — `lab-000N`, журнал — `.planning/LAB-RELEASES.md`,
подробности — `.planning/LAB-DEPLOY-RUNBOOK.md`, раздел 6.
