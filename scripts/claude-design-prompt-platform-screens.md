Сделай кликабельный HTML-прототип из ЧЕТЫРЁХ экранов платформы Klassio для живого демо (ведущий проходит путь целиком): **лендинг → регистрация → личный кабинет → запись прошедшего урока**. Klassio — AI-репетитор для школьников 1–7 класса; уроки голосом ведёт наставница Аня на интерактивных досках, потом родитель смотрит запись занятия.

## ⚠️ Главное правило — ДВА визуальных мира

**Мир 1 — Klassio (по умолчанию, 90% интерфейса).** Тёплый, минималистичный, пастельный: кремово-бежевые фоны, терракотовый акцент, мягкие песочные тени, крупные скругления, воздух. Настроение — как урок астрономии в референсе `anya.html`. Никакого синего, ничего «корпоративного».

**Мир 2 — ВТБ (партнёрский блок, точечно).** Финансовые уроки (карта, инвестиции) — это трек «при поддержке ВТБ». Только их карточки/секции одеваются в ВТБ-синий, визуально отделённые рамкой-блоком, чтобы читалось как ко-брендинг, а не как цвет платформы. Настроение — как урок карты в референсе `vtb-karta.html`.

Логика для демо простая и честная: платформа тёплая и детская, а финансовый трек — партнёрский с банком, поэтому эти уроки носят синий цвет банка.

## Палитра Klassio (Мир 1 — весь интерфейс, кроме финансового блока)

Возьми токены ровно отсюда (это боевые переменные проекта):

```
--bg-0:#FBF8F1;  --bg-1:#F6EFE3;  --bg-2:#EFE5D5;  --bg-3:#E7DAC6;   /* крем → песок */
--ink:#2C2922;   --ink-soft:rgba(44,41,34,.62);  --ink-faint:rgba(44,41,34,.40);  --ink-line:rgba(44,41,34,.08);
--accent:#CC7A50;  --accent-deep:#B5663E;  --accent-dark:#9E5F35;  --accent-soft:#DBA07A;  --accent-wash:rgba(204,122,80,.10);  /* терракота */
--av-1:#D8CFF2;  --av-2:#C7C0EE;  --av-3:#A6C6E9;   /* орб-аватар Ани — прохладная лавандово-голубая нота */
--sh-soft:0 2px 8px rgba(74,60,36,.05), 0 10px 30px rgba(74,60,36,.06);
--sh-raised:0 4px 14px rgba(74,60,36,.07), 0 24px 60px rgba(74,60,36,.10);
--r-card:30px;  --r-bub:20px;  --r-field:16px;
```

- Фон страниц: `--bg-1` + тёплое свечение сверху `radial-gradient(135% 90% at 50% -15%, #FBF8F1, transparent 62%)`. Можно добавить очень деликатную сетку/точки `rgba(44,41,34,.05)`.
- Карточки: фон `--bg-0`, radius 30px, тень `--sh-soft`, БЕЗ рамок и чёрного. Наведение — приподнять на 2px + `--sh-raised`.
- Кнопки-акции: заливка `--accent`, белый текст, pill (radius 999px), тень `0 10px 26px rgba(204,122,80,.34)`. Тихие кнопки — фон `--bg-2`, тёмный текст.
- Кикеры: терракота, uppercase, letter-spacing .12em, 12.5px, 700.
- Шрифт: Onest 400–800, letter-spacing -.005em, сглаживание.
- Аватар Ани — круглый орб с conic-градиентом `--av-1 → --av-3 → --accent-soft` (лавандово-персиковый, как в `anya.html`), НЕ синий квадрат.

## Палитра ВТБ (Мир 2 — только партнёрский финансовый блок и превью его уроков)

```
--vtb-navy0:#0A2456;  --vtb-navy1:#133B7A;   /* тёмно-синий градиент, обложки */
--vtb-brand:#1B4BD2;  --vtb-deep:#0F3AB0;  --vtb-accent:#2E5BFF;  --vtb-soft:#DCE7FF;
--vtb-card:#BFE0FF;    /* пластик карты */
```

Применяй ТОЛЬКО внутри блока «Финансовая грамотность · при поддержке ВТБ» и на превью-миниатюрах уроков карты/инвестиций. Внутри такого блока фон — синий градиент или очень светлый `#EDF3FB`, карточки-уроки синие, кнопка урока синяя `--vtb-brand`. Снаружи блока — снова тёплый Klassio.

## Лейаут (сохрани грамматику боевого кабинета — по ней я переношу 1:1)

- Контейнер: `max-width:760px`, центр, паддинги `28px 20px 80px` (страницы платформы — узкие и опрятные, НЕ во всю ширину). Лендинг может быть шире (до ~1080px) ради hero.
- **Топбар**: слева лого — квадратик-эмблема с градиентом `--av-1→--av-3` (radius 9px) + слово «классио» строчными, 700. Справа — контекстный чип (`Кабинет родителя` / кнопки входа).
- Карточки-«подушки», секции с кикером+заголовком, pill-чипы уведомлений (терракотовая заливка `--accent-wash`, текст `--accent-deep`).
- Анимации сдержанные: появление карточек снизу со stagger, лёгкое «дыхание» hero-мокапа, пульс статуса. Вся графика — inline-SVG/CSS кодом, БЕЗ растровых картинок.

## Экран 1 — Лендинг (`data-screen="landing"`, `#landing`)

Шире прочих (демо на проекторе). Тёплый Klassio.

1. **Топбар**: лого «классио»; справа «Войти» (тихая) и «Попробовать бесплатно» (терракотовая, → `#signup`).
2. **Hero**: слева заголовок «Живой урок с AI-репетитором. Голосом.» + саб «Аня объяснит тему, спросит, поможет с ошибкой и похвалит — как настоящий учитель, один на один. Уроки по 15–20 минут для 1–7 класса.» + CTA «Начать учиться» (→ `#signup`) и тихая «Как проходит урок». Справа — **тёплый** мини-мокап урока АСТРОНОМИИ кодом (НЕ карта, НЕ синий): кремовая доска с простым SVG — солнце/планеты терракотовыми тонами, орб-аватар Ани, пузырь чата Ани «Солнце — это огромная звезда, ближайшая к нам!», круглая терракотовая кнопка микрофона, статус «Аня говорит…». Мокап чуть «дышит».
3. **«Как проходит урок»** — 4 карточки: 🎙 Голос (Аня говорит и слушает, перебивать можно); 🖼 Доски (объясняет на интерактивных досках, схемы оживают); ✏️ Тренажёр (сразу закрепляем заданиями, Аня подсказывает); 📋 Запись (после урока родителям: диалог, ошибки, итоги).
4. **Предметы** — заголовок «Каталог растёт каждую неделю». Карточки предметов в тёплом стиле:
   - **Математика · 5 класс** — «Сложение в столбик», «Вычитание в столбик» (чип «скоро»).
   - **Окружающий мир · 4 класс** — «Мир глазами астронома» (зелёная точка «доступен»), «Планеты Солнечной системы», «Звёздное небо» (скоро).
   - Затем — **отдельная синяя партнёрская секция** (Мир 2): плашка «Финансовая грамотность · при поддержке ВТБ» на светло-синем/тёмно-синем фоне, внутри две синие карточки-урока: «Инвестиции для начинающих» и «Твоя первая банковская карта» (с мини-превью синей карты-кота). Явно выделена рамкой/фоном как «блок от банка».
5. **Родителям** — тёплый постановочный блок (тёмный вариант Klassio — глубокий терракотово-коричневый, НЕ синий): «Каждый урок — под запись», «Вы решаете» (лимиты времени, темы), «Безопасно» (дома, без незнакомцев).
6. **Футер**: «© 2026 классио · AI-репетитор для школьников».

## Экран 2 — Регистрация (`data-screen="signup"`, `#signup`)

Тёплый Klassio. По центру карточка-«подушка» на кремовом фоне, вокруг — пара деликатных SVG-звёздочек терракотой.
- Заголовок «Создаём кабинет», саб «Минута — и Аня познакомится с вашим ребёнком».
- Поля (radius 16px, фон `--bg-0`, тонкая линия `--ink-line`): Email родителя; Имя ребёнка; Класс — сегмент-кнопки 1–7 (не селект).
- Чекбокс «Согласен(на) на обработку персональных данных».
- Большая терракотовая кнопка «Создать аккаунт» → `#cabinet`, имя ребёнка из поля подставляется в приветствие кабинета (JS + localStorage, чтобы пережить F5).
- Тихая строка внизу «Уже есть аккаунт? Войти».

## Экран 3 — Личный кабинет (`data-screen="cabinet"`, `#cabinet`)

Тёплый Klassio (эталон — боевой кабинет). Топбар: лого + чип «Кабинет родителя» справа.

1. Приветствие: кикер «КАБИНЕТ РОДИТЕЛЯ» (терракота), h1 «Учёба Миши» (имя из формы, дефолт «Миши»), саб «Выберите предмет — внутри уроки и записи занятий».
2. **Сетка предметов** (тёплые карточки с эмодзи-иконкой на подложке `--accent-wash`):
   - Математика · 5 класс — чип «2 урока · скоро».
   - Окружающий мир · 4 класс — «Мир глазами астронома» доступен + 2 «скоро».
   - Финансовая грамотность — **синяя партнёрская карточка** (Мир 2, выделяется среди тёплых): чип «при поддержке ВТБ» + чип-уведомление «1 новый урок».
3. **Финансовый трек — раскрытая синяя секция** (гвоздь экрана, Мир 2, на светло-синем фоне `#EDF3FB` в рамке-блоке): плашка «Финансовая грамотность · при поддержке ВТБ», внутри:
   - карточка «Инвестиции для начинающих» — синяя, статус «пройден ✓», кнопка «Смотреть запись»;
   - КРУПНАЯ синяя карточка-герой «Твоя первая банковская карта» с мини-превью доски (карта-кот кодом, ВТБ-палитра), саб «Что умеет детская карта: оплата, приложение, безопасность и кешбэк», яркая синяя кнопка «Начать урок» (в проде → сам урок; в прототипе alert-заглушка ок).
4. **Записи уроков** (снова тёплый Klassio, вне синего блока): строка-карточка «Твоя первая банковская карта · сегодня · 18 минут · 13/13 заданий · ведёт Аня» с кнопкой «Открыть запись» → `#record`.

## Экран 4 — Запись урока (`data-screen="record"`, `#record`)

Хром — тёплый Klassio (это же экран кабинета). Урок про карту — партнёрский, поэтому на его бейдже допустима синяя ВТБ-нота, но фон и карточки страницы остаются кремовыми.

1. Шапка: «← Назад в кабинет» (→ `#cabinet`); h1 «Твоя первая банковская карта» + маленький синий чип «ВТБ»; мета-строка «Финансовая грамотность · сегодня, 16:40 · 18 минут · 13 из 13 заданий · ведёт Аня».
2. **«Замечания учителя»** — тёплая карточка на подложке `--accent-wash`, кикер «АНЯ · ПО ИТОГАМ УРОКА»: «Миша отлично разобрался, где живут деньги и как платить картой — здорово рассуждает вслух! Один раз запутался с PIN-кодом (задание 5) — повторите вместе: код вводим, прикрывая рукой, и не называем никому. Правила безопасности усвоил уверенно — на все три вопроса про мошенников ответил сразу. Мини-задание на вечер: вместе откройте приложение и найдите историю покупок.»
3. Чипы навыков (тёплые pill): Основы карты ✓ · Оплата ✓ (жёлтая метка «повторить PIN») · Приложение ✓ · Безопасность ✓ · Кешбэк ✓.
4. **Лента урока** — вертикальный таймлайн, диалог вперемешку с событиями платформы. Табы-фильтры сверху «Всё · Диалог · Ошибки · Инструменты» (работают простым JS — скрывают типы). Типы записей:
   - пузырь Ани (кремовый, метка «АНЯ») и пузырь ребёнка (терракотовый, метка «МИША») — как чат урока;
   - чип-событие инструмента (тонкая песочная строка с иконкой): «📋 Открыта доска „Правила безопасности“», «✏️ Задание 9 — „Ты потерял карту. Что сделать первым делом?“», «⭐ Награда: урок пройден»;
   - событие-ошибка (терракотово-красноватая строка `--error #C0392B`): «❌ Ответ „Никому не говорить и ждать“ — неверно»;
   - событие-успех (зелёная): «✅ Верно со 2-й попытки: „Заморозить карту в приложении и сказать родителям“».
   Наполни правдоподобным фрагментом (15–20 записей): знакомство («Привет! Я Аня. А как тебя зовут?» → «Миша» → событие «🧒 Имя ученика: Миша»), пара реплик теории про доску безопасности («Это самая важная страница. PIN-код — только твой секрет…»), задание 9 с ошибкой и мягким разбором («Не спеши. Вспомни: в приложении есть кнопка, которая „усыпит“ карту одним нажатием…»), верная вторая попытка, похвала, финал с наградой.

## Технический контракт (ОБЯЗАТЕЛЬНО — по нему я переношу в прод)

- ОДИН standalone HTML-файл, без библиотек/CDN (кроме Google Fonts Onest); графика — inline-SVG/CSS, растровых картинок не генерировать.
- 4 экрана = 4 секции `data-screen="landing|signup|cabinet|record"`; показ по `location.hash` (`#landing` дефолт), переключение без перезагрузки.
- Весь путь кликабелен: лендинг → регистрация → (сабмит с именем) → кабинет → «Открыть запись» → запись → «Назад».
- Токены Klassio — в `:root` ровно с именами выше (`--bg-0, --ink, --accent, --sh-soft…`). ВТБ-токены — отдельной группой (`--vtb-*`), применяются только в партнёрских блоках (например через класс-обёртку `.vtb`).
- Классы с префиксом экрана (`ld-`, `su-`, `cb-`, `rec-`).
- Имя ребёнка из формы → JS-переменная + localStorage → подставляется в кабинет («Учёба Миши», дефолт «Миши»).
- Лента записи: каждая запись — элемент с `data-kind="tutor|child|tool|wrong|solve"` (по нему работают табы-фильтры и моя интеграция).
- Голос в тексте для родителей — всегда «Аня» (имя наставницы), не называй TTS-вендора.
- Ничего не грузить с внешних доменов, кроме шрифта Onest.
