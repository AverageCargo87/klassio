# Тест Yandex: голос + LLM (без ручной сборки)

Два скрипта, чтобы (1) выбрать голос Ани и (2) сравнить LLM на вашем промпте тьютора и function-calling. Оба используют один API-ключ Yandex AI Studio.

## 1. Один раз — креды в `.env.local`
```
YC_API_KEY=<API-ключ из AI Studio → «Создать API-ключ»>
YC_FOLDER_ID=b1g...   # ID каталога «default»
```
- **Folder ID**: консоль Yandex Cloud → твой каталог `default` → ID вида `b1g...` (в обзоре каталога / в URL).
- **Права ключа**: у твоего текущего ключа scope был `yc.ai.imageGen` — этого мало. Если скрипты вернут **401/403**, создай API-ключ для сервис-аккаунта с ролями `ai.languageModels.user` + `ai.speechkit-tts.user` (и `ai.speechkit-stt.user` на будущее).

## 2. Голоса Ани → слушаем
```
node --env-file=.env.local scripts/yandex-voice-sample.mjs
```
Складывает по MP3 на голос в `scripts/voice-samples/`. Открой папку, послушай, выбери тёплый (не «дикторский»). Кандидатов правь в массиве `VOICES` наверху скрипта; скорость — `SPEED`.
*(Если ВСЕ голоса пропущены с ошибкой про `format` — поменяй в скрипте `format:'mp3'` на `format:'oggopus'`.)*

## 3. LLM → сравниваем
```
node --env-file=.env.local scripts/yandex-llm-compare.mjs
```
Прогоняет 3 сценария, где Аня **должна** вызвать инструмент (назвал имя → `set_child_name`; после разминки → `next_slide`; верный ответ → следующий шаг), через модели из `MODELS`. Печатает: вызвала ли нужный tool (✅/⚠️/❌), что именно, задержку, токены, ~цену.

Добавить DeepSeek V4 Flash / Alice AI LLM: открой их в **Model Gallery**, скопируй строку `gpt://<folder>/<id>/latest` и впиши `id` в массив `MODELS`.

## Что смотреть в результатах
- **Function-calling** — главное: у кого стабильно ✅ во всех 3 сценариях, тот годится под управление доской.
- **Задержка** — для реалтайма важна; Lite обычно быстрее Pro.
- **Цена** — Lite в разы дешевле; точное потребление в консоли → **Мониторинг → Детализация**.
