# LESSON-FLOW.md — механика AI-урока (контракт)

> Статус: согласовано Кратов ↔ Claude, июнь 2026. Поворот от тренажёр-first к **AI-репетитор-first** (Владимир).
> Это контракт механики. От него строим: wireframe → бэкенд+голос → тест.

---

## 1. Продукт одной фразой

AI-репетитор ведёт живой голосовой урок: здоровается, болтает, считывает состояние ребёнка и **достаёт инструменты (доска / тренажёр / фото) только когда нужно**. В основе — пустой минималистичный canvas. Не перегруженный интерфейс.

## 2. Аккаунт и роли

- **1 аккаунт = семья.**
- **Родитель** — владелец. Регистрируется (magic link). Смотрит результаты, прогресс, уведомления (включая поведение).
- **Ребёнок** — заходит, жмёт «начать урок», проходит. Ничего не настраивает.
- `/cabinet` = два лица под одним логином: «запустить урок» (ребёнок) + «отчёты/уведомления» (родитель).

## 3. Визуальный язык

- **Chrome (одинаков для всех уроков):** бежевый/кремовый минимализм, много воздуха, тёплая типографика, плавные анимации. Стиль «как Claude Design».
- **Theme (меняется per урок):** живёт ВНУТРИ инструментов. Космос для астрономии — внутри доски, не в chrome.
- Учитель = **аватар-кружок с именем + статус** (слушает/говорит/думает).
- **Чат-транскрипт**: реплики учителя и ребёнка, появляются плавно по словам, синхронно с речью учителя.
- Десктоп first.

### 3.1 Баланс «воздух vs контент» (ключевой принцип, Кратов+Владимир)

Кажущееся противоречие: пустой минимализм в разговоре, но богатый контент в обучении. Разрешается формулой **«богато по сумме урока, минималистично в каждый момент»**:

- **Временно́е разделение.** Разговорные фазы (приветствие/smalltalk/пауза/прощание) — пустой холст. Обучающие (теория/практика) — контент в центре.
- **Один фокус за раз.** В отличие от плотной инфографики-референса (где таймлайн+словарь+схема+задания на одной странице ОДНОВРЕМЕННО), у нас эти элементы появляются ПО ОДНОМУ в центре, сменяя друг друга. На экране всегда один блок + воздух вокруг.
- **Progressive build синхронно с речью.** Контент собирается кусками в такт голосу учителя: говорит про орбиты → появляются орбиты; про размер → появляется сравнение. Не вываливать всё сразу. «Интересно смотреть и слушать параллельно» = визуал иллюстрирует то, что произносится ПРЯМО СЕЙЧАС.
- **Богатство — внутри одного блока, не в количестве блоков.** Доска Солнечной системы может быть детальной и живой (вращение, клик по планете) — но это ОДИН блок по центру, а не 6 панелей по краям.

Референс-PDF (испанские инфографики) ценны педагогической плотностью, но их формат «всё на одной странице» — это ровно то, что мы РАЗВОРАЧИВАЕМ во времени: тот же объём контента проходит за урок, но никогда не виден весь сразу.

## 4. Фазы урока (state machine)

```
ПОДКЛЮЧЕНИЕ → РАЗОГРЕВ → [ДИАГНОСТИКА*] → МОСТИК
   → ⟳ ЦИКЛ: теория→практика, адаптивная сложность ⟲
        ↑ (пауза при усталости)   ↓ (трекинг каждой попытки)
   → ИТОГ → ПРОЩАНИЕ
```

| # | Фаза | Учитель | Canvas |
|---|---|---|---|
| 1 | Подключение | Появляется, здоровается по имени | пусто |
| 2 | Разогрев (1-2 мин) | «Как дела? Что интересного?», считывает baseline | пусто |
| 3 | Диагностика* | вплетённые в разговор вопросы разного уровня (1-й урок) | пусто |
| 4 | Мостик | связывает тему с интересами ребёнка | пусто |
| 5 | Цикл обучения ⟳ | теория(голос+доска) → практика(тренажёр) → реакция | инструмент выезжает/уходит |
| 6 | Пауза | по сигналу усталости: отвлечённый разговор → возврат | пусто |
| 7 | Итог | recap, похвала, ⭐ | доска/звёзды |
| 8 | Прощание | «в следующий раз…», домашка | пусто |

*Диагностика растворена в разговоре, не отдельный тест-экран. На след. уроках — лёгкая калибровка по прошлым результатам.

## 5. Инструменты учителя (client tools)

Учитель «достаёт» их голосовым решением; отработал → инструмент уходит, canvas снова пустой.

| Инструмент | Когда | Статус |
|---|---|---|
| 🖼 Доска | схема/рисунок/иллюстрация (Солнечная система), карточки слов | ✅ есть (tldraw + /api/draw + доски) |
| 🎯 Тренажёр | интерактивная задача с проверкой | ✅ есть (типы задач) |
| 📷 Фото-окно | реальные снимки космоса | ⚙️ заготовка |
| ⭐ Награда | звезда/веха прогресса | 🆕 |
| ☕ Пауза | смена режима (не картинка) — отдых/разговор | 🆕 |

## 6. Сигнал → реакция (минимальный набор, БЕЗ эмоций голоса)

| Сигнал (как меряем) | Источник | Реакция |
|---|---|---|
| Пауза перед ответом > N сек | 11labs timing | «Подумай, я подожду» → подсказка проще |
| Растут паузы между словами | 11labs timing | флаг усталости |
| 2-3 ошибки подряд | state-счётчик | сбавить, объяснить проще, достать доску |
| Быстро + верно подряд | state | усложнить, ускорить |
| Слова «устал/скучно/не хочу» | transcript | → фаза ПАУЗА |
| Долгое молчание | 11labs | «Ты тут?» |
| Вопрос не по теме | агент | коротко ответить → вернуть |
| first / N-й урок | таблица lessons | разный сценарий |

Детект усталости v1 = 3 числа, фронт считает → шлёт агенту через `sendContextualUpdate`: (1) среднее время реакции, (2) ошибки подряд, (3) минут идёт урок (>15-20 для 9-летки → пора пауза). Решение принимает промпт агента.

## 7. Три слоя поверх всех фаз

- **📊 Трекинг** — per задание: верно/нет · попытки · время · подсказка · время реакции. Агрегаты per ученик: освоенные темы · слабые места · скорость · вовлечённость. Новые таблицы Neon (lesson_attempts / skill_mastery / progress_events). Кормит: адаптивность + ЛК родителя + следующий урок.
- **🎚 Адаптивность** — сложность под ответы; 1-й урок задаёт стартовую программу; след. уроки от прогресса.
- **⚠️ Модерация поведения** — мат/грубость (дети будут): 1) предупреждение «так нельзя, иначе расскажу родителям» → 2) повтор → запись в БД + уведомление в ЛК родителя → 3) опц. мягкий стоп-урок. **Два слоя: серверный фильтр (надёжный детект) + промпт агента (как реагировать).** Отличается от контент-модерации (safety того что учитель говорит). Согласуется с invariant «модерация для детей не опциональна».
